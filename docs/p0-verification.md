## Фактически выполнено

На 390 px трассировки в одну колонку, страница без горизонтальной прокрутки; SVG-схемы сохраняют собственную прокручиваемую область.

Главная, Java languages, SQL-практикум и IT lecture-01 проверены при 1440 и 390 px: шапка, загрузка материалов, отсутствие JS/HTTP ошибок и запросов WOFF. SQL-движок запускается и выполняет COUNT. Движение моделей в рамках P0 не менялось.

`python -m unittest discover -s tests -v` проверяет хеши исходников, неизменность git status, одинаковый результат двух сборок и идемпотентность общей обработки. После трёх коммитов сборка повторяется с чистым git status. HTML трёх контрольных страниц сравнивается побайтно с публикацией после завершения Pages.

Это проверка перечисленного объёма, не полный аудит доступности всего сайта. Safari/iOS и Firefox в этой сессии не проверялись. Задачи P1/P2 и motion.patch не применялись.
