# P1: фактический объём и проверка

## Реализовано
- T4: уникальные title/description и OG в артефакте для всех 54 HTML, canonical, Twitter summary, 404 с рабочими абсолютными базовыми ссылками, robots и sitemap для 53 реальных документов (404 исключена).
- T5: 54 материала, 8749 слов, индекс 149165 байт. Полнотекстовая область включает содержание лекций/работ; исключены скрипты, меню и повторный конспект. Общий словарь с префиксным сжатием и postings сохраняет все индексируемые слова. Ленивая загрузка по фокусу, debounce120мс, ранжирование, подсветка через DOM, стрелки/Enter/Escape и сообщение об ошибке загрузки.
- T6: один h1 в каждом HTML; один h1 на активном SPA-экране, отдельный доступный заголовок читалки; в SQL главный заголовок относится к активной лекции. В конспектах уровни понижены с сохранением ID, оглавление их не захватывает.
- T7: сохранение scroll iframe и прямых страниц с обработкой ошибок localStorage; section имеет приоритет, закрытые details раскрываются. Deep links вида route/section, прямая ссылка на раздел из оглавления, «Открыть отдельно» с текущим разделом.
- T11: шаг автопоказа1800мс, переход240мс без снижения читаемости текста; цепочки timeout, отмена при паузе/скрытии и переключении reduce, неподвижные SVG-стрелки на паузе. SVG-анимация не заменяет координатный transform группы. Стабильная высота кода, единые токены и короткий переход страниц без затухания, тяжёлый движущийся фон отключён.

## Выполненные проверки
`python scripts/build.py`; `python -m unittest discover -s tests -v` — source isolation/idempotence, уникальные метаданные, один h1, сохранение anchors и полнотекстовые fixtures. CI выполняет эти проверки перед Pages.

Headless Chrome/Chromium на Windows: поиск DEX→обзор языков, транзакция→продвинутыйSQL, инкапсуляция→конструкторы/ООП, массив→массивы. Проверены lazyfetch и клавиатура. На тёплом индексе обработка запроса около2,5мс (без сетевого ожидания и debounce).

Ссылка #java-languages/lecture-_6 попадает к разделу; возврат после ухода из лекции восстановил scroll1300→1300; прямой HTML восстановил1500px. Проверены внешняя ссылка, смена SQL-лекции и одинh1 в её документе.

Обычный и reduced-motion: trace/arrays/OOP next/reset/play/pause; после паузы шаг не меняется, SVGпунктирpaused, при reduce нет runninganimations. На 390px высота кода не менялась по шагам. В локальной пятисекундной headless-проверке трёх моделей: около60fps, LongTask>50мс не наблюдались. Это измерение одной машины, а не гарантия для всех устройств.

## Честные ограничения
Разные OG для hash-маршрутов невозможны на статическом хостинге: используйте прямой HTML-адрес. SQL остаётся одним документом до P2. Реальные превью в Telegram/VK, Safari/iPhone и Firefox в этой сессии не проверялись. Индекс не включает архивные/преподавательские файлы и повторный конспект; это поиск по опубликованному основному учебному тексту. Полный Lighthouse и P2 в эту итерацию не входят.

Финальная проверка поиска: совпадение по началу слова исключает DEX внутри index; выдержки берутся из учебных объяснений, без подписей и подсказок моделей.
