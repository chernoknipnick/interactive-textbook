# Проверка светлой и тёмной темы — 16.11.2026

## Поведение

- Начальное состояние — светлая тема. Переключатель в шапке доступен как `switch` с именем «Тёмная тема» и состоянием `aria-checked`.
- Проверены Space и Enter, сохранение при перезагрузке, применение в текущем iframe, переход к следующей лекции и синхронизация второй вкладки.
- При искусственном запрете `localStorage` переключатель продолжает работать, текущая и следующая встроенная лекция наследуют тему родительской страницы. Сохранение между сеансами в таком случае невозможно.
- На ширинах 320, 390, 768, 1100 и 1440 px шапка сохраняет высоту 52 px. Проверены главная, Java и ИТ: кнопки не перекрываются, горизонтального переполнения нет. На узком экране остаётся значок темы, длинное название дисциплины сокращается.
- Эмуляция печати из тёмной темы: белый фон, чёрный основной текст. Цветовые переопределения тёмной темы действуют только на экране.

## Читаемость

Chrome, reduced motion, axe-core 4.14.0 (`color-contrast`): все 54 HTML-страницы в тёмной теме без обнаруженных нарушений. Дополнительно проверены начальные страницы SQL-лекций 02–05 и конечные состояния всех моделей Java. Ошибок JavaScript не обнаружено.

В светлой теме проверены главная, обзор языков, ссылки, заключение ООП, SQL-лекция, SQL-практикум, ИТ-лекция и кабинет. Исправлены слабые цвета атрибутов/декораторов Java, заголовков SQL, подписей ИТ и терминала. Окна новостей и предложений отдельно проверены в тёмной теме.

Вручную в браузере проверены переключение, SQL-запрос с результатами, ошибочный и правильный ответ в тесте. Скриншоты главной, лекций и кабинета рассмотрены независимым UX-критиком: блокирующих замечаний по коду и этим экранам нет. Геометрию мобильной шапки проверял основной агент.

Автоматическая проверка контраста не охватывает текст внутри растровых иллюстраций и не заменяет проверку всех возможных пользовательских данных. Иллюстрации курсов сохраняют собственные светлые фоны.

## Сборка

`python -m unittest discover -s tests -v`: 5 проверок пройдены. Подтверждены неизменность исходников после подготовки, повторяемость сборки, подключение раннего скрипта темы и двух палитр во всех HTML, метаданные, заголовки и размер поискового индекса.
