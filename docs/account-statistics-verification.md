# Кабинет и статистика — 16.11.2026

## Причина мигания

Раньше обработчик `onAuthStateChange` вызывал полную загрузку при каждом событии. Повторный `SIGNED_IN` на возвращении в окно/вкладку и `TOKEN_REFRESHED` запускали `getUser`, профиль, группы и предложения; во время загрузки `dashboard` скрывался. Инициализация дополнительно запускала загрузку одновременно с `INITIAL_SESSION`.

Теперь `INITIAL_SESSION` — единственный стартовый запуск, повторный ID игнорируется, а ротация токена не перезагружает данные кабинета. Реальная смена пользователя, выход и восстановление пароля очищают приватную панель; события обрабатываются вне блокировки Auth. Ручные действия и кнопки обновления запрашивают актуальные данные без скрытия уже открытого кабинета. Обычные запросы обновления токена библиотекой Auth сохраняются.

События проверены по [документации Supabase](https://supabase.com/docs/reference/javascript/auth-onauthstatechange).

## Проверки

`python supabase/test_access.py --pg-bin "C:/Program Files/PostgreSQL/18/bin"` прошёл на отдельном временном кластере PostgreSQL. Проверены запрет статистики и каталога для анонима, студента и другого преподавателя; запрет самостоятельной выдачи прав; отсутствие прямого доступа к `auth.users`; точные московские границы 7 дней; уникальные участники нескольких групп; 14 дней с нулями; поиск без интерпретации `%`; сортировка и разделение 25/5 строк; повторная миграция без потери роли. Существующие проверки групп и предложений также проходят.

После `python scripts/build.py` браузерная регрессия запускается:

```sh
python tests/browser/check_account.py
# Дополнительно, при наличии локальной копии axe-core:
python tests/browser/check_account.py --axe "путь/к/axe.min.js"
```

Требуются Playwright Python и установленный Chrome по пути, указанному в проверке. Сервер стартует на случайном локальном порту и подменяет только SDK тестовыми данными. Эти файлы находятся вне `dist/` и не публикуются.

Пройдено: одна стартовая загрузка; серии `SIGNED_IN`/`TOKEN_REFRESHED`, события focus/visibility и смена браузерных вкладок без новых обращений к данным, скрытия dashboard, потери несохранённого имени, поискового запроса или раскрытых разделов. Проверены фильтрация, пагинация, безопасный вывод HTML в имени, сворачивание предложений, нулевые значения, ошибка/повтор, вход, восстановление, выход и смена пользователя во время отложенного ответа. Физическое нажатие Alt+Tab в Windows не воспроизводилось: проверялся тот же обработчик событий возврата окна.

Контраст axe-core 4.14.0 и отсутствие общего горизонтального переполнения проверены для светлой/тёмной темы на 320, 390, 768 и 1440 px. Таблица пользователей прокручивается внутри своего блока. Предпросмотр с тестовыми числами отдельно осмотрен в браузере.

Миграция `003_admin_statistics.sql` применена в рабочем проекте Supabase после подтверждения владельца. Общий доступ выдан одному подтверждённому преподавательскому аккаунту; результат проверен в SQL Editor (`is_administrator=true`). Проверка авторизованной панели на основном сайте требует входа владельца: доступная встроенная вкладка не содержит его пользовательской сессии.
