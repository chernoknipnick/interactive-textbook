# Проверка навигации учебника · 11 ноября 2026

Результат: отдельный агент-критик принял изменения после двух проверок исходников. Это экспертная оценка интерфейса, а не исследование с участием студентов.

## Основа решений
- W3C: понятная иерархия и постоянная навигация: https://www.w3.org/WAI/WCAG2/supplemental/patterns/o2p02-site-structure/
- W3C: несколько способов найти материалы, включая поиск: https://www.w3.org/WAI/tutorials/menus/multiple-ways/
- NN/g: последовательность, узнаваемые действия, видимое текущее положение: https://www.nngroup.com/articles/ten-usability-heuristics/

## Исправления по замечаниям критика
- Убрали большой декоративный первый экран; выбор дисциплины расположен сразу после поиска.
- Названия курсов стали основными заголовками, добавлен путь к материалу.
- Поиск по заголовкам Java, SQL и ОП.03 с дисциплиной, типом материала и пустым состоянием. Поиск не индексирует полный текст лекций.
- Лекции Java и SQL представлены компактными нумерованными списками; отдельные переходы к практике.
- Предыдущий и следующий материалы в оболочке Java/SQL. Для ОП.03 сохранена навигация самих лекций.
- Последний открытый материал запоминается только в этом браузере; это не оценка и не отметка о выполнении.
- Длинные названия не вытесняют нижние кнопки на телефоне; Escape возвращает фокус только из открытого меню.
- Новости перенесены в верхнее меню, чтобы кнопка не перекрывала переходы.

## Проверка в браузере
Проверены поиск и отсутствие результатов, возврат к Java/ОП.03, путь и соседние материалы, меню и фокус с клавиатуры, экраны 320/375/768/901/1024/1100/1101/1365 px, работа Java-модели и SQL-запросов, форма предложений и окно новостей. Без реальной отправки студенческих данных.

## Следующая проверка с учащимися
Попросить найти заданную лекцию, открыть практическую и вернуться к текущей теме без подсказки. Наблюдать ошибки и затраты времени; по ним корректировать интерфейс.


## Пересмотр по замечаниям преподавателя: читаемость
Светлая версия заменяет предыдущую тёмную схему. Шапка 52 px; путь внутри полосы управления. Поиск в меню удалён. Новости и помощь внутри «Ещё»; автоматический всплывающий тост скрыт.

Крупные номера ПР/ЛР — основной ориентир в списке работ. Шрифт содержания 18 px; единый файл light.css подключается ко всем страницам. Внутри предмета шапка показывает Java/SQL/информационные технологии и свой акцент, не меняя правил оформления текста.

Java: тезисы составлены отдельно для 14 тем; ОП.03: тезис взят из существующего «Под запись»; SQL: тезисы для пяти лекций. Это краткие опорные мысли, полный текст сохранён. Подсказка о цветах закрыта. Учебные анимации сохранены, добавлены короткие переходы с учётом prefers-reduced-motion.

Агент-критик повторно проверил светлую версию. Найден и исправлен низкий контраст старых SQL-токенов. Приёмка по исходникам, без утверждения о тестировании учащимися. В браузере проверены переходы между разделами SQL, последовательность тем, Java-модель, SQL-движок, формы, меню, размеры 320–1440 px. Внешние шрифты исключены из HTML, чтобы не задерживать открытие лекций.


## Карточки и сворачиваемое содержание
Исправлен источник наложения кнопки ПР02: внешняя сетка работ теперь в одну колонку, а внутри строки используются container queries по её доступной ширине (820 и 440 px). Полный код предмета убран из крупного номера: предмет уже назван заголовком раздела. Все номера ПР/ЛР отображаются с пробелом.

В карточках дисциплин — три локальные SVG-иллюстрации: окно программы, база данных, информационная система. Они имеют фиксированную ограниченную область и пустой alt, поскольку название предмета уже присутствует рядом.

Java: базовый уровень, алгоритмы, объекты/ООП. SQL: основы и запросы. Границы групп закреплены явными ID. Группа текущей темы автоматически открывается в sidebar; в обзоре группы управляются нативными details/summary. Все 14 тем Java имеют отдельное описание. Названия в select сокращены, полные названия сохранены в заголовках.

Проверены 320, 375, 600, 770, 900, 1100, 1440 px: кнопка внутри границ строки, не перекрывает заголовок/описание; все темы доступны; SVG загружаются; текущая группа раскрывается. Агент-критик принял изменения по исходникам. Переход страниц больше не снижает прозрачность текста.
