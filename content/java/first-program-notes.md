# 0.5. Первая программа на Java: структура и запуск — под запись




## Обобщение: подставь свои имена

Это шаблон, а не готовая программа:

```text
public class ИмяКласса {
    public static void main(String[] args) {
        инструкции;
    }
}
```

ИмяКласса выбираешь ты и используешь согласованно в файле и команде запуска. Вместо инструкций помещается конкретный код. В показанном способе запуска main сохраняет своё имя и подходящий заголовок. Это не название произвольного метода, которое можно заменить без изменения способа запуска.

## 1. Запуск программы на Java — два шага

```
HelloWorld.java ──[javac]──► HelloWorld.class ──[java]──► результат
 исходный текст              байт-код          запуск JVM
```

1. **Компиляция:** `javac HelloWorld.java` — компилятор проверяет текст и создаёт файл `HelloWorld.class` с байт-кодом. Если в тексте есть ошибка, файл `.class` не создаётся.
2. **Запуск:** `java HelloWorld` — виртуальная машина загружает класс `HelloWorld` и выполняет его.

**Исходный файл** (`.java`) — текст программы, который пишет человек.
**Файл класса** (`.class`) — байт-код, который создаёт компилятор и выполняет JVM.

Кнопка «Запуск» в онлайн-компиляторе и в среде разработки выполняет оба шага подряд.

## 2. Структура программы

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Привет, мир!");
    }
}
```

```
┌─ класс HelloWorld ─────────────────────────┐
│  ┌─ метод main ─────────────────────────┐  │
│  │   инструкция: вывести текст          │  │
│  └──────────────────────────────────────┘  │
└────────────────────────────────────────────┘
```

**Структура программы на Java:** класс → метод → инструкции.

**Класс** — основная единица кода в Java. Весь код программы находится внутри классов.
**Метод** — именованный блок кода внутри класса, который выполняет действие.
**Инструкция** — одна команда программы. Каждая инструкция заканчивается точкой с запятой `;`.
**Блок** — код между фигурными скобками `{` и `}`. Каждая открывающая скобка должна иметь закрывающую.

**Правило имени файла:** имя файла должно совпадать с именем `public`-класса с точностью до регистра букв. Класс `HelloWorld` → файл `HelloWorld.java`.

**Java различает регистр букв:** `Main`, `main` и `MAIN` — три разных имени.

Имена классов пишут с большой буквы: `HelloWorld`, `Calculator`.

## 3. Точка входа

**Точка входа** — метод, с которого виртуальная машина начинает выполнение программы. В Java это метод
`public static void main(String[] args)`.
Эта строка пишется всегда одинаково.

| Слово | Что означает | Зачем в `main` |
|---|---|---|
| `public` | метод доступен снаружи класса | JVM вызывает `main` снаружи |
| `static` | метод принадлежит классу, а не объекту | в момент запуска ни одного объекта ещё нет |
| `void` | метод ничего не возвращает | `main` не отдаёт результат, а выполняет действия |
| `main` | имя метода | именно это имя ищет JVM |
| `String[] args` | входные данные: массив строк | аргументы командной строки |

## 4. Вывод на экран

`System.out.println("текст");` — вывести текст на экран и перейти на новую строку.
`System` — встроенный класс; `out` — канал вывода в консоль; `println` — метод вывода.
**Строка** — текст в двойных кавычках: `"Привет, мир!"`.

`System.out.print(...)` — вывести и остаться на той же строке.
`System.out.println(...)` — вывести и перейти на новую строку.

```java
System.out.print("Раз, ");
System.out.print("два, ");
System.out.println("три!");
System.out.println("Конец");
```

```
Раз, два, три!
Конец
```

**Знак `+`:** между числами — сложение; если хотя бы один из операндов — строка, то склейка (конкатенация). Выражение вычисляется слева направо, скобки — в первую очередь.

`"Сумма: " + 5 + 3` → `Сумма: 53`
`"Сумма: " + (5 + 3)` → `Сумма: 8`
`5 + 3 + " — сумма"` → `8 — сумма`

## 5. Комментарии

**Комментарий** — текст в программе, который компилятор пропускает; пояснение для человека.

```java
// текст — до конца строки

/* текст — от этого знака до закрывающего,
   может занимать несколько строк */
```

## 6. Ошибки

**Ошибка компиляции** — ошибку находит компилятор до запуска. Программа не запускается вообще. Сообщение начинается со слова `error` и содержит номер строки.
**Ошибка выполнения** — программа скомпилировалась и запустилась, но остановилась во время работы.

| Сообщение | Перевод | Что искать |
|---|---|---|
| `';' expected` | ожидалась `;` | пропущена точка с запятой в указанной строке |
| `cannot find symbol` | не найдено имя | опечатка или неверный регистр в имени |
| `reached end of file while parsing` | файл кончился раньше времени | не хватает закрывающей `}` |
| `unclosed string literal` | незакрытая строка | не хватает закрывающей `"` |
| `class X is public, should be declared in a file named X.java` | имя класса не совпадает с именем файла | переименовать класс или файл |
| `Main method not found in class X` | не найден метод `main` | ошибка в строке `public static void main(String[] args)` |

**Порядок чтения ошибки:** 1) номер строки; 2) текст после слова `error`; 3) галочка `^` под местом ошибки. Исправлять начинают с первой ошибки в списке: остальные часто являются её следствием.
