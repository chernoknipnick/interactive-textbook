# Часть А. Переменные и типы



## Обобщение: подставь свои имена

Это шаблон, где подписи заменяются настоящими типами, именами и выражениями:

```text
Тип имяПеременной = начальноеЗначение;
имяПеременной = новоеВыражение;
```

Тип повторно не пишется при обычном изменении существующей переменной. `int count = 3; int count = 4;` в той же области — повторное объявление, а не обновление значения.

В учебных именах используй понятные слова. Java различает регистр. Одиночное подчёркивание нельзя использовать как обычное имя переменной в современных версиях Java; более широкие правила идентификаторов не означают, что любое сочетание знаков допустимо.

## 1. Переменная

**Переменная** — именованная область памяти, в которой хранится значение определённого типа.
У переменной есть **тип**, **имя** и **значение**.

**Объявление** — создание переменной: `int age;`
**Присваивание** — запись значения в переменную: `age = 18;`
**Инициализация** — объявление вместе с первым присваиванием: `int age = 18;`

Общий вид: `тип имя = значение;`

```java
int age = 18;                            // создать и положить 18
System.out.println(age);                 // 18
age = 19;                                // изменить (тип второй раз не пишется)
System.out.println("Возраст: " + age);   // Возраст: 19
```

Знак `=` — команда «положить значение справа в переменную слева», а не математическое равенство.

**Правила имён переменных:**
1. состоят из букв, цифр, знаков `_` и `$`; не начинаются с цифры;
2. не совпадают с ключевыми словами (`int`, `class`, `public` и т. д.);
3. регистр важен: `age` и `Age` — разные переменные.

**Соглашение:** имя переменной пишут с маленькой буквы, каждое следующее слово — с большой, без пробелов и подчёркиваний: `studentAge`, `totalPrice`. Имя должно говорить, что хранится: `price`, а не `a`.

| Сообщение компилятора | Причина |
|---|---|
| `variable x might not have been initialized` | переменную читают до первого присваивания |
| `variable x is already defined` | переменную объявили второй раз |
| `incompatible types: possible lossy conversion from double to int` | значение не подходит по типу |

## 2. Примитивные типы

**Примитивные типы** — восемь базовых типов, встроенных в язык: `byte`, `short`, `int`, `long` (целые); `float`, `double` (дробные); `char` (символ); `boolean` (логический).

| Тип | Что хранит | Размер | Диапазон | Пример |
|---|---|---|---|---|
| `byte` | целое | 1 байт | −128 … 127 | `byte level = 5;` |
| `short` | целое | 2 байта | −32 768 … 32 767 | `short year = 2026;` |
| **`int`** | целое | 4 байта | ≈ ±2,1 миллиарда | `int age = 18;` |
| `long` | целое | 8 байт | ≈ ±9,2 · 10¹⁸ | `long views = 5000000000L;` |
| `float` | дробное | 4 байта | ≈ 7 значащих цифр | `float weight = 72.5f;` |
| **`double`** | дробное | 8 байт | ≈ 15 значащих цифр | `double price = 19.99;` |
| **`char`** | одна кодовая единица UTF-16 | 2 байта | 0 … 65 535 | `char grade = 'A';` |
| **`boolean`** | логическое | — | `true` или `false` | `boolean isReady = true;` |

**Что использовать по умолчанию:**
- целое число → `int`;
- дробное число → `double`;
- да/нет → `boolean`;
- одна кодовая единица UTF-16, например буква A → `char`; для произвольного текста — String;
- целое больше двух миллиардов → `long`.

`byte`, `short`, `float` применяют редко: когда нужно экономить память в больших массивах.

## 3. Литералы

**Литерал** — значение, записанное прямо в коде программы.

| Запись | Тип | Примечание |
|---|---|---|
| `18` | `int` | любое целое без суффикса |
| `5000000000L` | `long` | суффикс `L` |
| `19.99` | `double` | любое число с точкой |
| `72.5f` | `float` | суффикс `f` |
| `'A'` | `char` | одинарные кавычки, одна кодовая единица UTF-16 |
| `"A"` | `String` | двойные кавычки, сколько угодно символов |
| `true`, `false` | `boolean` | без кавычек |

В длинных числах для удобства можно ставить подчёркивание: `1_000_000`.
Дробная часть отделяется точкой, а не запятой: `3.14`.

## 4. Переполнение и точность

**Переполнение** — выход результата за границы диапазона типа. Java не сообщает о переполнении: результат «перескакивает» на другой край диапазона.
`2147483647 + 1` → `-2147483648`.
Если результат может превысить два миллиарда, используют `long`.

**Дробные числа хранятся приближённо.** `0.1 + 0.2` → `0.30000000000000004`.
1. Дробные числа не сравнивают через `==`.
2. Деньги не хранят в `double`: суммы считают в копейках в типе `long` или в специальном классе `BigDecimal`.

## 5. Символ и строка

**`char`** — одна кодовая единица UTF-16 в одинарных кавычках: `'A'`. Хранится как 16-битное беззнаковое значение; для A оно совпадает с кодом Unicode (`'A'` = 65).
**`String`** — строка, последовательность символов в двойных кавычках: `"Анна"`. Это не примитивный тип, а класс; у строки есть методы, например `name.length()` — длина строки.

```java
char letter = 'A';
System.out.println((int) letter);          // 65
System.out.println((char) (letter + 1));   // B
```

**Примитивные типы** хранят само значение. Их восемь, имена пишутся с маленькой буквы.
**Ссылочные типы** хранят ссылку на объект в памяти. К ним относятся `String`, массивы и все классы; имена пишутся с большой буквы.

## 6. Константы

**Константа** — переменная, значение которой нельзя изменить после инициализации. Объявляется словом `final`:
`final double PI = 3.14159;`
Имена констант пишут заглавными буквами через подчёркивание: `MAX_SCORE`.

# Часть Б. Операции и преобразование типов

## 7. Арифметические операции

| Знак | Операция | Пример | Результат |
|---|---|---|---|
| `+` | сложение | `7 + 2` | `9` |
| `-` | вычитание | `7 - 2` | `5` |
| `*` | умножение | `7 * 2` | `14` |
| `/` | деление | `7 / 2` | `3` |
| `%` | остаток от деления | `7 % 2` | `1` |

**Целочисленное деление:** если оба операнда целые, результат деления — целое число, дробная часть отбрасывается: `7 / 2` → `3`. Если хотя бы один операнд дробный, результат дробный: `7 / 2.0` → `3.5`.

**Остаток от деления `%`:** `7 % 2` → `1`.
Применение:
- проверка чётности: `n % 2` равно 0 → число чётное;
- последняя цифра числа: `1234 % 10` → `4`; число без последней цифры: `1234 / 10` → `123`;
- перевод единиц: `135 / 60` → 2 часа, `135 % 60` → 15 минут.

**Порядок действий:** сначала `*`, `/`, `%`, потом `+`, `-`; операции одного приоритета — слева направо; скобки меняют порядок.
`2 + 3 * 4` → `14`; `(2 + 3) * 4` → `20`.

Деление целого числа на ноль — ошибка выполнения `ArithmeticException: / by zero`.

## 8. Присваивание, инкремент, декремент

**Составные операции присваивания**

| Короткая запись | Полная запись |
|---|---|
| `x += 5` | `x = x + 5` |
| `x -= 5` | `x = x - 5` |
| `x *= 5` | `x = x * 5` |
| `x /= 5` | `x = x / 5` |
| `x %= 5` | `x = x % 5` |

**Инкремент** `x++` — увеличить на 1. **Декремент** `x--` — уменьшить на 1.

`y = x++;` — постфиксная форма: сначала значение `x` используется, потом увеличивается.
`y = ++x;` — префиксная форма: сначала `x` увеличивается, потом используется.
Если `x++` стоит отдельной инструкцией, разницы нет.

```java
int x = 5;
int y = x++;   // y = 5, x = 6
int z = ++x;   // x = 7, z = 7
```

## 9. Операции сравнения

Результат — значение типа `boolean`.

| Знак | Значение | Пример | Результат |
|---|---|---|---|
| `==` | равно | `5 == 5` | `true` |
| `!=` | не равно | `5 != 5` | `false` |
| `>` | больше | `5 > 3` | `true` |
| `<` | меньше | `5 < 3` | `false` |
| `>=` | больше или равно | `5 >= 5` | `true` |
| `<=` | меньше или равно | `5 <= 3` | `false` |

`=` — присваивание («положить»). `==` — сравнение («равны ли?»).

**Строки сравнивают методом `equals`, а не знаком `==`:**
`a.equals(b)` — `true`, если текст строк совпадает.
`==` для строк сравнивает идентичность объектов, а не текст.

## 10. Логические операции

Работают со значениями `boolean`, результат — `boolean`.

| Знак | Название | Когда `true` |
|---|---|---|
| `&&` | И | оба операнда `true` |
| `\|\|` | ИЛИ | хотя бы один операнд `true` |
| `!` | НЕ | операнд `false` |

| `a` | `b` | `a && b` | `a \|\| b` | `!a` |
|---|---|---|---|---|
| `true` | `true` | `true` | `true` | `false` |
| `true` | `false` | `false` | `true` | `false` |
| `false` | `true` | `false` | `true` | `true` |
| `false` | `false` | `false` | `false` | `true` |

Двойное неравенство записывают двумя сравнениями: `age >= 14 && age < 18`.

**Сокращённое вычисление:** если результат ясен по первому операнду, второй не вычисляется. Для `&&`: первый `false` → результат `false`. Для `||`: первый `true` → результат `true`.

**Приоритет:** `!` → арифметика → сравнения → `&&` → `||`. В сложных условиях ставят скобки.

## 11. Преобразование типов

```
          расширение: обычно без явного приведения; точность может теряться ──────►
byte → short → int → long → float → double
          ◄────── сужение: обычно явно, возможна потеря
```

**Расширяющее преобразование** обычно разрешено без явного приведения. В цепочке ниже не все целые значения сохраняют точность при переходе к float или double: например, long → double может округлить число. Автоматическое преобразование не обещает отсутствия потерь точности.

**Сужающее преобразование** может терять данные; в обычном выражении его явно задают приведением `(тип) значение`. Для некоторых константных присваиваний действуют специальные разрешения, например `byte level = 5`.
`(int) 10.9` → `10` (дробная часть отбрасывается, а не округляется).
Округление по правилам математики: `Math.round(10.9)` → `11`.

**Тип результата обычной бинарной числовой арифметики** определяется числовым продвижением. byte, short и char обычно сначала становятся int; далее учитываются long, float и double. Например:
`int` и `int` → `int`; `int` и `double` → `double`; `int` и `long` → `long`.

**Ловушка среднего значения:**
`double average = sum / count;` при целых `sum` и `count` даёт целый результат (`3.0`).
Правильно: `double average = (double) sum / count;`

```
double average = sum / count;
                 └────┬────┘
              1) int / int = 3
└──────┬──────┘
 2) 3 → 3.0
```

## 12. Строка ↔ число

**Преобразование между строкой и числом** выполняется методами, а не приведением типа.

| Что нужно | Как | Пример |
|---|---|---|
| строка → целое | `Integer.parseInt(строка)` | `Integer.parseInt("25")` → `25` |
| строка → дробное | `Double.parseDouble(строка)` | `Double.parseDouble("3.5")` → `3.5` |
| число → строка | `String.valueOf(число)` | `String.valueOf(10)` → `"10"` |

Если строка не является числом, `parseInt` вызывает ошибку выполнения `NumberFormatException`.
