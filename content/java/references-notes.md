# 1.1.7. Ссылки (указатели в Java) — под запись

> МДК.01.03 «Разработка мобильных приложений». Это то, что должно быть в тетради после пары. Схемы памяти нужно уметь рисовать.

## 1. Две области памяти

**Стек** — область памяти, где хранятся локальные переменные методов. Переменная существует, пока выполняется её метод.
**Куча** — область памяти, где хранятся объекты: массивы, строки и всё, что создано через `new`.

**Переменная примитивного типа** хранит само значение.
**Переменная ссылочного типа** хранит **ссылку** — адрес объекта в куче. Сам объект находится в куче.

**Ссылка** — значение, по которому программа находит объект в памяти.

```java
int age = 18;
int[] marks = {5, 4, 3};
String name = "Анна";
```

```
        СТЕК                         КУЧА
 age   ┌──────┐
       │  18  │
       └──────┘                 ┌───┬───┬───┐
 marks ┌──────┐                 │ 5 │ 4 │ 3 │
       │  ●───┼────────────────►└───┴───┴───┘
       └──────┘                 ┌──────────┐
 name  ┌──────┐                 │ "Анна"   │
       │  ●───┼────────────────►└──────────┘
       └──────┘
```

Восемь примитивных типов хранят значение; все остальные типы (их имена с большой буквы или с `[]`) хранят ссылку.

`System.out.println(marks)` выводит не элементы, а описание ссылки вида `[I@1b6d3586`.

## 2. Присваивание ссылки

**Присваивание ссылки** `b = a` копирует ссылку, а не объект. После него обе переменные указывают на **один и тот же** объект: изменение объекта через `b` видно через `a`.

Чтобы получить независимую копию массива, нужно создать новый массив: `Arrays.copyOf(a, a.length)`.

```
int[] b = a;

a ┌───┐
  │ ●─┼──┐    ┌─────┬───┬───┐
  └───┘  ├──► │ 100 │ 2 │ 3 │
b ┌───┐  │    └─────┴───┴───┘
  │ ●─┼──┘
  └───┘
```

| Запись | Что меняется |
|---|---|
| `b[0] = 100;` | объект, на который указывает `b` (это видно через все ссылки на него) |
| `b = new int[3];` | только переменная `b`: она начинает указывать на другой объект |

## 3. Строки неизменяемы

**Строки неизменяемы.** Строку, созданную в памяти, изменить нельзя.
- Операции и методы строк (`+`, `toUpperCase()`, `trim()`, `replace()`) создают **новую** строку и возвращают её.
- Чтобы сохранить результат, его присваивают: `name = name.toUpperCase();`
- Поэтому строки при присваивании ведут себя «как значения»: изменение `s1` не затрагивает `s2`.

```java
String name = "анна";
name.toUpperCase();              // результат потерян, name = "анна"
name = name.toUpperCase();       // name = "АННА"
```

## 4. Сравнение

**`==` для ссылочных типов сравнивает ссылки:** `true`, только если обе переменные указывают на один и тот же объект.
**`equals` сравнивает содержимое объектов.** Для массивов — `Arrays.equals(a, b)`.

**Пул строк** — область памяти, где Java хранит строковые литералы без повторов. Поэтому `"да" == "да"` может дать `true`, но строки, полученные при работе программы (ввод, файл, сеть), в пул не попадают.
**Строки и любые объекты по содержимому сравнивают только через `equals`.**

## 5. `null` и `NullPointerException`

**`null`** — значение ссылочной переменной, которая не указывает ни на какой объект.
- Значение по умолчанию для элементов массивов строк и других ссылочных типов.
- `null` можно присвоить, вывести, сравнить через `==`.

**`NullPointerException`** — ошибка выполнения: обращение через точку (вызов метода, поле) к ссылке, равной `null`.

**Защита — проверка перед обращением:**
`if (name != null && name.length() > 0) { ... }`
Порядок условий важен: при `name == null` вторая часть не вычисляется (сокращённое вычисление).

```java
String name = null;
System.out.println(name);            // null
System.out.println(name.length());   // NullPointerException
```

`null` и пустая строка `""` — разные вещи: `""` — это объект, строка длины 0.

## 6. Ссылки и методы

**В метод всегда передаётся копия значения переменной.** Для ссылочного типа копируется ссылка.
- Метод **может изменить объект**, на который указывает ссылка: `numbers[0] = 100;` — изменение видно в вызывающем методе.
- Метод **не может заменить объект** вызывающего метода: `numbers = new int[3];` меняет только копию ссылки внутри метода.

```java
static void fill(int[] numbers) {
    numbers[0] = 100;                 // меняет общий массив — видно в main
}

static void replace(int[] numbers) {
    numbers = new int[] {7, 7, 7};    // меняет только свою копию ссылки — в main не видно
}
```

## 7. Сборщик мусора, ссылки и указатели

**Сборщик мусора** (garbage collector) — часть JVM, которая автоматически освобождает память объектов, на которые не осталось ни одной ссылки.

**Указатель** (в C, C++) — переменная с адресом памяти, с которым можно выполнять арифметику; память освобождает программист.
**Ссылка в Java** — адрес объекта без арифметики и без ручного освобождения памяти. Это безопаснее: нельзя обратиться к чужой или освобождённой памяти.
