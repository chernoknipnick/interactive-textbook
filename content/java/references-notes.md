# 1.1.7 Ссылки — Под запись

#java #ооп #конспект


## Определения

**Ссылка** — значение, с помощью которого Java обращается к объекту. Ссылочная переменная хранит ссылку на объект или `null`.

**Присваивание** копирует значение правой части в переменную слева. Копирование ссылки само по себе не создаёт копию объекта.

**`null`** — специальное значение, означающее отсутствие ссылки на объект.

**В Java аргументы передаются по значению:** метод получает копию значения аргумента. Для ссылочного типа копируется значение ссылки.

**Строка `String` неизменяема:** содержимое существующего строкового объекта изменить нельзя.

## Разберись на трёх строках

`int[] first = {10, 20};` — создали массив. `int[] second = first;` — скопировали ссылку, массив по-прежнему один. `second[0] = 99;` — изменили общий массив, поэтому `first[0]` тоже 99.

`second = new int[]{7, 8};` перенаправляет только `second`. Через `first` остаётся прежний массив. Метод тоже получает отдельную переменную-параметр: изменение элементов общего массива видно вызывающему коду, а переназначение параметра — нет.

`null` не равен пустому массиву. Перед чтением `.length` у потенциально отсутствующего массива нужна проверка. У `String` сравниваем текст методом `equals`, а не `==`. Для других классов смысл `equals` зависит от реализации.
