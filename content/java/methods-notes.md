# 1.1.6. Методы (процедуры и функции) — под запись

> МДК.01.03 «Разработка мобильных приложений». Это то, что должно быть в тетради после пары. После темы — практическая работа ПР03.

## 1. Зачем нужны методы

**Метод** — именованный блок кода, который выполняет определённую задачу и может быть вызван по имени.

**Зачем нужны методы:**
1. **нет повторений** — код пишется один раз, вызывается много раз; ошибка исправляется в одном месте;
2. **читаемость** — имя метода говорит, что делает код: `findMax(scores)`;
3. **разделение задачи** — большую программу разбивают на небольшие части, каждую пишут и проверяют отдельно.

Метод без возвращаемого значения называют **процедурой**, метод с возвращаемым значением — **функцией**.

## 2. Объявление и вызов

```
static   int    square  (int x)   {
  │       │       │        │
  │       │       │        └ параметры: что метод получает
  │       │       └ имя метода
  │       └ тип возвращаемого значения: что метод отдаёт
  └ метод принадлежит классу

    return x * x;        ← тело метода
}
```

**Объявление метода:**

```java
static тип_возврата имяМетода(параметры) {
    тело метода
}
```

- **тип возврата** — тип значения, которое метод отдаёт; `void`, если ничего не отдаёт;
- **имя** — с маленькой буквы, начинается с глагола: `printLine`, `findMax`, `calculateAverage`;
- **параметры** — входные данные метода; скобки пишутся, даже если параметров нет;
- **тело** — код между `{` и `}`.

Методы объявляются внутри класса, **рядом** с `main`, а не внутри него.

**Объявление** описывает, что делает метод. **Вызов** запускает его выполнение: `имяМетода(аргументы);`
Объявленный, но ни разу не вызванный метод не выполняется.

```java
public class Main {
    public static void main(String[] args) {
        printLine();                          // вызов
        System.out.println("Отчёт по группе");
        printLine();                          // вызов
    }

    static void printLine() {                 // объявление
        System.out.println("--------------------");
    }
}
```

Порядок методов в классе не важен: выполнение всегда начинается с `main`.

## 3. Параметры и аргументы

**Параметр** — переменная в объявлении метода, которая принимает входное значение: `static void greet(String name)`.
**Аргумент** — конкретное значение, которое передаётся в метод при вызове: `greet("Анна")`.

```
greet("Анна");                      ← аргумент: конкретное значение
        │
        ▼ копируется
static void greet(String name) {    ← параметр: переменная, которая его принимает
```

При вызове аргументы копируются в параметры **по порядку**. Количество и типы аргументов должны соответствовать параметрам.
Тип указывается у каждого параметра отдельно: `(int a, int b)`.

## 4. Возврат значения

**`return значение;`** — завершает метод и возвращает значение в место вызова.

```java
static void printSquare(int x) {     // процедура: выводит
    System.out.println(x * x);
}

static int square(int x) {           // функция: возвращает
    return x * x;
}
```

| | `void`-метод (процедура) | Метод с возвратом (функция) |
|---|---|---|
| Тип возврата | `void` | `int`, `double`, `boolean`, `String`… |
| Что даёт | выполняет действие | вычисляет и отдаёт значение |
| `return` | не обязателен | обязателен, тип значения должен совпадать с типом возврата |
| Как вызывают | `printSquare(5);` | `int r = square(5);` |

**Вывести и вернуть — разные вещи.** `System.out.println` показывает значение человеку. `return` отдаёт значение программе, чтобы она могла использовать его дальше.
Метод, который вычисляет результат, должен его возвращать, а не печатать: вызывающий сам решит, что с ним делать.

Что можно сделать с возвращённым значением:

```java
int a = square(5);                     // сохранить
System.out.println(square(5));         // вывести
int sum = square(3) + square(4);       // использовать в выражении
if (square(5) > 20) { ... }            // использовать в условии
```

`return` завершает метод сразу: код после него не выполняется.
Метод с типом возврата не `void` должен возвращать значение **при любом** ходе выполнения, в том числе во всех ветках `if`.
Метод возвращает только одно значение.

Метод, возвращающий `boolean`:

```java
static boolean isEven(int n) {
    return n % 2 == 0;
}
```

## 5. Как выполняется вызов

```
main:  int result = square(5);
                      │  ▲
          1) переход  │  │  3) возврат: на место вызова
             x = 5    ▼  │     подставляется 25
square:        return x * x;
               2) вычисление: 25
```

**Локальная переменная** — переменная, объявленная внутри метода (включая параметры). Существует только во время выполнения этого метода и не видна в других методах.

**Передача по значению:** в метод передаётся копия значения аргумента. Изменение параметра внутри метода не меняет переменную в вызывающем методе.
Чтобы получить изменённое значение, его возвращают: `x = addOne(x);`

```java
int x = 5;
addOne(x);                  // внутри метода n стало 6
System.out.println(x);      // 5 — переменная x не изменилась
```

## 6. Методы и массивы

```java
static int findMax(int[] numbers) {
    int max = numbers[0];
    for (int i = 1; i < numbers.length; i++) {
        if (numbers[i] > max) {
            max = numbers[i];
        }
    }
    return max;
}

static double calculateAverage(int[] numbers) {
    int sum = 0;
    for (int i = 0; i < numbers.length; i++) {
        sum += numbers[i];
    }
    return (double) sum / numbers.length;
}
```

Вызов: `int best = findMax(groupA);`

## 7. Перегрузка

**Сигнатура метода** — имя метода вместе со списком типов его параметров: `max(int, int)`. По сигнатуре компилятор определяет, какой метод вызван.

**Перегрузка методов** — несколько методов с одним именем, но разными списками параметров (по количеству или по типам). Компилятор выбирает нужный метод по аргументам вызова.
Методы, которые отличаются только типом возврата или только именами параметров, перегруженными не являются: это ошибка компиляции.
Пример из стандартной библиотеки: `System.out.println` принимает `String`, `int`, `double`, `boolean`…

```java
static int max(int a, int b) { ... }
static double max(double a, double b) { ... }
static int max(int a, int b, int c) { ... }
```

## 8. Сообщения об ошибках

| Сообщение | Причина |
|---|---|
| `non-static method … cannot be referenced from a static context` | у метода забыли `static` |
| `illegal start of expression` | метод объявлен внутри другого метода |
| `missing return statement` | метод с возвратом не возвращает значение на каком-то пути |
| `unreachable statement` | код написан после `return` |
| `'void' type not allowed here` | пытаются использовать результат `void`-метода |
| `method … cannot be applied to given types` | количество или типы аргументов не соответствуют параметрам |
| `method … is already defined` | два метода с одинаковым именем и одинаковыми параметрами |
