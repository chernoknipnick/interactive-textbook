# 1.2.1. Классы и объекты — под запись

> МДК.01.03 «Разработка мобильных приложений». Это то, что должно быть в тетради после пары.

## 1. Зачем нужны классы

**Проблема параллельных массивов:** данные об одном объекте разнесены по разным массивам и связаны только одинаковым индексом. При сортировке, добавлении и удалении данные легко рассогласовать.
**Решение:** собрать все данные об объекте в одну конструкцию — **класс**.

```java
String[] names = {"Анна", "Борис", "Вера"};   // имя Анны — names[0],
double[] marks = {4.8, 3.9, 4.5};             // её балл — marks[0]: связь только через индекс
```

## 2. Класс и объект

**Класс** — описание (шаблон) нового типа данных: какие данные будут у каждого объекта и какие действия он может выполнять.
**Объект** (экземпляр класса) — конкретный представитель класса, созданный по этому описанию, со своими значениями данных.

**Поле** — переменная, объявленная в классе; хранит данные объекта.
**Метод** — действие, которое умеет выполнять объект.

Класс один — объектов может быть сколько угодно, у каждого свои значения полей.

```
        КЛАСС Student                    ОБЪЕКТЫ
    ┌──────────────────┐          ┌──────────────────┐
    │ поля:            │          │ name = "Анна"    │
    │   name           │ ──new──► │ age = 17         │
    │   age            │          │ averageMark = 4.8│
    │   averageMark    │          └──────────────────┘
    │ методы:          │          ┌──────────────────┐
    │   printInfo()    │ ──new──► │ name = "Борис"   │
    │   isExcellent()  │          │ age = 18         │
    └──────────────────┘          │ averageMark = 3.9│
                                  └──────────────────┘
```

## 3. Объявление класса и создание объекта

**Объявление класса**

```java
class Student {
    String name;          // поля
    int age;
    double averageMark;
}
```

**Создание объекта:** `Student anna = new Student();`
`new` создаёт объект в куче; в переменной сохраняется ссылка на него.

**Обращение к полю:** `объект.поле` — `anna.name = "Анна";`, `System.out.println(anna.age);`

В одном файле — только один `public`-класс, его имя совпадает с именем файла. Остальные классы в том же файле пишутся без `public`; обычно каждый класс помещают в отдельный файл.

**Поля получают значения по умолчанию:** числа — `0`, `boolean` — `false`, ссылочные типы — `null`. Локальные переменные значений по умолчанию не получают.

```java
public class Main {
    public static void main(String[] args) {
        Student anna = new Student();
        anna.name = "Анна";
        anna.age = 17;
        System.out.println(anna.name + ", " + anna.age + " лет");
    }
}

class Student {
    String name;
    int age;
    double averageMark;
}
```

## 4. Объекты — это ссылки

Переменная типа класса хранит **ссылку** на объект.
- `Student s2 = s1;` — две ссылки на один объект.
- `s1 == s2` — `true`, только если это один и тот же объект.
- `Student s = null;` — ссылка без объекта; `s.name` даст `NullPointerException`.

```
 s1 ┌───┐
    │ ●─┼──┐    ┌───────────────────┐
    └───┘  ├───►│ name = "Вера"     │
 s2 ┌───┐  │    │ age = 0           │
    │ ●─┼──┘    └───────────────────┘
    └───┘
```

## 5. Методы объекта

**Метод объекта** объявляется в классе без слова `static` и вызывается через объект: `anna.printInfo();`
Внутри метода поля объекта доступны по имени: `name` — это поле того объекта, у которого вызван метод.

```java
class Student {
    String name;
    int age;
    double averageMark;

    void printInfo() {
        System.out.println(name + ", " + age + " лет, средний балл " + averageMark);
    }

    boolean isExcellent() {
        return averageMark >= 4.5;
    }

    void birthday() {
        age++;
    }
}
```

`anna.printInfo()` выводит данные Анны, `boris.printInfo()` — данные Бориса: код один, объекты разные.

| | `static`-метод | Метод объекта |
|---|---|---|
| Принадлежит | классу | каждому объекту |
| Как вызвать | `Main.square(5)` или `square(5)` | `anna.printInfo()` — только через объект |
| Видит поля объекта | нет | да |
| Пример | `main`, `Math.round`, `Integer.parseInt` | `name.length()`, `scanner.nextInt()` |

Ошибка `non-static method … cannot be referenced from a static context` — метод объекта вызван без объекта. Исправление: вызвать через объект, а не дописывать `static`.

## 6. Массив объектов

**Массив объектов:** `Student[] group = new Student[3];`
Массив хранит **ссылки**; сразу после создания все элементы равны `null`. Каждый объект нужно создать: `group[0] = new Student();`

Обход: `for (Student s : group) { ... s.name ... }`

```java
Student best = group[0];
for (Student s : group) {
    if (s.averageMark > best.averageMark) {
        best = s;
    }
}
System.out.println("Лучший средний балл: " + best.name);
```

## 7. Метод `toString`

**`toString()`** — метод, который возвращает строковое представление объекта. Java вызывает его автоматически при выводе через `println` и при склейке со строкой.

```java
@Override
public String toString() {
    return name + " (" + age + " лет)";
}
```

Без `toString` объект выводится как `Student@1b6d3586`.

## 8. Принципы ООП

**Объектно-ориентированное программирование (ООП)** — подход, при котором программа строится из объектов, объединяющих данные и действия.

**Четыре принципа ООП:**
1. **Абстракция** — в классе описываются только существенные для задачи свойства (у студента для журнала важны имя и оценки, но не цвет глаз).
2. **Инкапсуляция** — данные и методы объединены в классе, а прямой доступ к данным ограничен. (Тема 1.2.2.)
3. **Наследование** — новый класс создаётся на основе существующего и получает его поля и методы. (Тема 1.2.4.)
4. **Полиморфизм** — один и тот же вызов метода по-разному работает для объектов разных классов. (Тема 1.2.4.)
