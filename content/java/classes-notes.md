# 1.2.1 Классы и объекты — Под запись

#java #ооп #конспект


## Определения

**Класс** — описание типа объектов: какие данные они хранят и какие действия доступны для них.

**Объект** — конкретный экземпляр класса со своим состоянием. У одного класса может быть много объектов.

**Поле объекта** — переменная, принадлежащая конкретному объекту и хранящая часть его состояния.

**Метод объекта** — действие, вызываемое для конкретного объекта и способное работать с его состоянием.

**`this`** — ссылка на текущий объект внутри его экземплярного метода или конструктора.

**Инкапсуляция** — объединение данных и поведения в классе и управление доступом к состоянию через выбранный интерфейс.

## Общая форма и выбранные имена

Это шаблон, а не готовая программа: подписи замени подходящими именами и типами.

```text
class ИмяКласса {
    ТипПоля имяПоля;
    ТипРезультата имяМетода() {
        ...
    }
}

ИмяКласса имяПеременной = new ИмяКласса();
имяПеременной.имяМетода();
```

Student, anna, energy и study — выбранные имена. Их можно заменить другими допустимыми именами, согласованно изменив объявления и обращения. Слова class, new, void и знаки синтаксиса заданы Java. Готовый println произвольно переименовать нельзя. Имя конструктора совпадает с именем класса; имя main сохраняется для принятого способа запуска.

## Как читать создание объекта

`Student anna = new Student();`: `Student` — тип; `anna` — переменная; `new Student()` — создание; `=` — сохранение ссылки.

Класс похож на шаблон карточки, объект — на конкретную заполненную карточку с доступными действиями. `anna.energy` и `boris.energy` принадлежат разным объектам. В `anna.study()` текущий объект — Анна; внутри метода `this` обозначает её объект.

`Student partner = anna;` создаёт вторую ссылку на Анну, а не нового студента. `Student[] group = new Student[2];` создаёт массив с двумя `null`; студентов нужно создать отдельно или поместить ссылки на существующих.

Поля имеют начальные значения по умолчанию, локальные переменные нельзя читать до присваивания. На следующем уроке закроем поля и будем задавать данные при создании.

## Разобрать каждую строку

Подробные объяснения каждой записи, трассировка полного примера и пошаговый переход к Phone: [[Классы и объекты — Разбор каждой строки]]. На сайте этот разбор включён в полную лекцию «Классы и объекты».

| Запись | Что происходит |
|---|---|
| `Student anna;` | Объявляется локальная переменная, объект не создан |
| `anna = new Student();` | Создаётся экземпляр, полученная ссылка присваивается anna |
| `anna.energy = 70;` | Меняется поле конкретного объекта |
| `anna.study();` | Вызывается действие у этого объекта |
| `Student partner = anna;` | Копируется ссылка на прежний объект |
| `anna == partner` | Проверяется, один ли это объект |

Границы условий: study при энергии 9 отказывает и оставляет 9; при 10 допускает занятие и оставляет 0. isTired при 29 возвращает true, при 30 — false. rest при 95 оставляет 100, а не 115.

`return;` завершает текущий вызов, а не всю программу. Для void нет значения, которое можно присвоить. У `boolean isTired()` значение есть: его можно сохранить в переменную или передать в if.
