# 1.2.3 Статические поля и методы — Под запись

#java #ооп #конспект


## Определения

**Экземплярное поле** — поле, отдельная переменная которого существует у каждого экземпляра класса.

**Статическое поле (`static`)** — поле класса, не создаваемое заново для каждого экземпляра. В наших примерах у одного загруженного класса одна такая общая переменная.

**Статический метод (`static`)** вызывается без текущего экземпляра. У него нет `this`, но он может работать с объектами, явно полученными или созданными в его коде.

**`final`** запрещает повторное присваивание переменной после её допустимой инициализации. Само по себе это не означает неизменяемости объекта, на который ведёт ссылка.

**`static final`** часто используют для констант класса; например, `static final int MAX_ENERGY = 100`.

## Личное и общее

| Вопрос | Экземпляр | Класс |
|---|---|---|
| Данные | `name`, `energy` каждого студента | общий `static createdCount` |
| Вызов | `anna.getEnergy()` | `Student.getCreatedCount()` |
| Нужен текущий объект | Да | Нет |
| Есть `this` | В экземплярном коде | В статическом методе нет |

Счётчик увеличиваем один раз в основном конструкторе после проверки. Вторая ссылка на уже существующий объект не увеличивает его. Число созданий не равно числу живых объектов.

`static` означает принадлежность классу, `final` — запрет повторного присваивания. `static final int MAX_ENERGY = 100` — общая числовая константа. `final`-ссылка не запрещает менять содержимое изменяемого объекта.

Статический метод может работать с явно переданным объектом: у него отсутствует только неявный текущий экземпляр. Личную энергию студента не надо делать `static` ради удобства вызова.
