# 1.1.3. Условный оператор: if, if-else, switch — под запись




## Обобщение: подставь свои имена

```text
if (логическоеУсловие) {
    действияПриИстине;
}

if (логическоеУсловие) {
    действияПриИстине;
} else {
    действияПриЛжи;
}
```

Имена и сравнения выбираешь по задаче. Слова if и else, скобки и структура фиксированы. Условие должно давать boolean: в Java число 1 само по себе не заменяет true.

## 1. Ветвление и оператор `if`

**Ветвление** — выполнение разных участков программы в зависимости от условия.

**Оператор `if`** выполняет блок кода, только если условие истинно:

```java
if (условие) {
    // выполняется, если условие равно true
}
```

**Условие** — выражение типа `boolean`. Круглые скобки вокруг условия обязательны.
Если условие равно `false`, блок пропускается целиком.

```java
int percent = 5;

if (percent < 10) {
    System.out.println("Осталось меньше 10% — подключите зарядку");
}
System.out.println("Проверка завершена");   // выполняется всегда
```

После условия точка с запятой **не ставится**: `if (x > 5);` — ошибка, которую компилятор не замечает.
Фигурные скобки ставят всегда, даже если в блоке одна инструкция.
Код внутри блока пишут с отступом в четыре пробела.

## 2. Ввод с клавиатуры — класс `Scanner`

```java
import java.util.Scanner;                    // 1. подключить (первая строка файла)

Scanner scanner = new Scanner(System.in);    // 2. создать (один раз, в начале main)
int n = scanner.nextInt();                   // 3. прочитать
```

| Метод | Что читает | Тип результата |
|---|---|---|
| `nextInt()` | целое число | `int` |
| `nextDouble()` | дробное число | `double` |
| `next()` | одно слово (до пробела) | `String` |
| `nextLine()` | всю строку до Enter | `String` |

**`import`** подключает класс из другого пакета. **`new`** создаёт объект класса.
`System.in` — ввод с клавиатуры, `System.out` — вывод на экран.

Если `nextInt()` получает не число, возникает ошибка выполнения `InputMismatchException`. Защита — проверить ввод заранее:

```java
if (scanner.hasNextInt()) {
    int percent = scanner.nextInt();
    System.out.println("Вы ввели: " + percent);
} else {
    System.out.println("Ошибка: нужно ввести целое число");
}
```

## 3. Оператор `if-else`

**Оператор `if-else`** выбирает один из двух блоков:

```java
if (условие) {
    // выполняется, если условие true
} else {
    // выполняется, если условие false
}
```

Выполняется **ровно одна** ветка: никогда обе и никогда ни одной.
У `else` нет условия. `else` без `if` не существует.

Два `if` подряд — это две независимые проверки: могут сработать оба или ни один. Если варианты исключают друг друга, используют `if-else`.

## 4. Цепочка `else if`

**Цепочка `else if`** — выбор одного из нескольких вариантов:

```java
if (условие1) {
    ...
} else if (условие2) {
    ...
} else if (условие3) {
    ...
} else {
    // если ни одно условие не подошло
}
```

Условия проверяются **сверху вниз**. Выполняется блок **первого** истинного условия, остальные не проверяются.
Последний `else` необязателен; без него может не выполниться ни одна ветка.
**Порядок условий важен:** более узкое условие ставят раньше более широкого.

```java
if (percent < 0 || percent > 100) {
    System.out.println("Некорректное значение");
} else if (percent < 10) {
    System.out.println("Критически низкий заряд");
} else if (percent < 30) {
    System.out.println("Пора зарядить");
} else {
    System.out.println("Заряда достаточно");
}
```

Проверка программы с ветвлением: по одному значению на каждую ветку и значения на границах (здесь: 0, 9, 10, 29, 30, 100).

## 5. Что может стоять в условии

- сравнение: `age >= 18`
- логическое выражение: `age >= 14 && age < 18`
- переменная типа `boolean`: `isReady`
- вызов метода, возвращающего `boolean`: `scanner.hasNextInt()`, `name.equals("Анна")`

**Полезные методы строк для условий** (все возвращают `boolean`):

| Метод | Когда `true` |
|---|---|
| `s.equals("да")` | текст совпадает полностью |
| `s.equalsIgnoreCase("да")` | совпадает без учёта регистра: `Да`, `ДА` |
| `s.startsWith("+7")` | строка начинается с указанного текста |
| `s.isEmpty()` | строка пустая |

Строки в условии сравнивают через `equals`, а не через `==`.

**Область видимости:** переменная, объявленная внутри блока `{ }`, существует только до закрывающей скобки этого блока.

```java
String message = "Норма";      // объявлена до if — видна и после него
if (percent < 10) {
    message = "Мало";
}
System.out.println(message);
```

## 6. Оператор `switch`

**Оператор `switch`** сравнивает одно значение с несколькими вариантами:

```java
switch (переменная) {
    case значение1:
        ...
        break;
    case значение2:
    case значение3:        // два значения — один код
        ...
        break;
    default:               // если ничего не подошло
        ...
        break;
}
```

- `case` — точка входа: выполнение начинается с совпавшего `case`.
- `break` — выход из `switch`. Без `break` выполнение **проваливается** в следующий `case`.
- `default` — выполняется, если ни один `case` не совпал; необязателен.
- `switch` работает с целыми типами, `char`, `String` и перечислениями. **Не работает** с `double`, `boolean` и с диапазонами.

```java
switch (day) {
    case 6:
    case 7:
        System.out.println("Сегодня выходной");
        break;
    case 5:
        System.out.println("Сегодня пятница — почти выходной");
        break;
    default:
        System.out.println("Сегодня рабочий день");
        break;
}
```

Запись со стрелкой (Java 14+): `case 6, 7 -> действие;` — без `break` и без проваливания.

**Что выбрать**

| Ситуация | `if / else if` | `switch` |
|---|---|---|
| Диапазоны: `x < 10`, `x >= 30` | да | нет |
| Разные условия с разными переменными | да | нет |
| Дробные числа | да | нет |
| Одна переменная и набор конкретных значений | можно, но длинно | да |

## 7. Тернарная операция

**Тернарная операция** выбирает одно из двух значений:
`условие ? значение_если_true : значение_если_false`
`String status = age >= 18 ? "взрослый" : "несовершеннолетний";`

## 8. Ошибки, которые компилятор не замечает

| Что написано | Что происходит |
|---|---|
| `if (x > 5);` | блок после условия выполняется всегда |
| строки сравниваются через `==` | условие ложно при одинаковом тексте |
| нет `break` в `switch` | выполняются лишние ветки |
| широкое условие стоит раньше узкого | часть веток никогда не выполняется |
| два `if` вместо `if-else` | могут сработать оба |

Начиная с этой темы «программа запустилась» не означает «программа работает». Каждую ветку нужно проверить запуском.
