# Лекция 0. Введение в курс. Разработка мобильных приложений

> Курс: МДК.01.03 «Разработка мобильных приложений» (ПМ.01, специальность 09.02.07). Объём — 172 часа. Полная структура курса: [[Колледж/Группы/КСП 09.02.07.39/JAWA/Навигатор|Навигатор]].

## Зачем этот курс

Мобильные приложения — самый массовый способ, которым сегодня пользуются программным обеспечением: у среднего человека телефон в руках занимает больше времени, чем компьютер. Курс даёт полный путь от «что такое переменная» до собственного рабочего Android-приложения с базой данных и обращением к серверу — то есть закрывает как фундамент программирования, так и специфику мобильной платформы.

К концу курса вы будете уметь:
- писать программы на Java и Kotlin — с типами данных, условиями, циклами, массивами, методами;
- проектировать код в объектно-ориентированном стиле (классы, наследование, полиморфизм);
- разрабатывать интерфейс Android-приложения, обрабатывать события, работать с несколькими экранами;
- хранить данные локально (SQLite) и знать основы работы с сервером (REST, облачные платформы);
- защищать данные простыми криптографическими приёмами и понимать структуры данных, на которых строится любое приложение (списки, деревья, хеш-таблицы).

## Два языка вместо одного — и почему это не удвоенная нагрузка

Официальная программа курса написана под **Java** — экзаменационные вопросы, формулировки практических работ («Реализация сортировок в библиотечных классах Java») ссылаются именно на неё. Мы будем следовать программе и разбирать Java подробно — она и сегодня остаётся основным языком старых и части новых Android-проектов, а её виртуальная машина (JVM) и модель памяти — база, без которой не понять, что вообще происходит на платформе.

Одновременно с этим мы будем показывать тот же код на **Kotlin** — официальном языке Google для Android-разработки с 2019 года и языке, на котором сегодня начинают почти все новые Android-проекты. Это не два разных курса, а один: Kotlin работает на той же виртуальной машине (JVM), что и Java, полностью совместим с ней (можно вызывать Java-код из Kotlin и наоборот) и решает те же задачи короче и безопаснее (например, `null` контролируется на уровне типов, а не падает исключением в рантайме).

Практический эффект такого подхода: вы будете понимать код на собеседовании или в существующем проекте независимо от того, на каком из двух языков он написан — а это на реальном рынке труда встречается постоянно, потому что переход индустрии с Java на Kotlin ещё не завершён.

```java
// Java
String greeting = "Привет, Android!";
int count = greeting.length();
```

```kotlin
// Kotlin — то же самое, короче и без явного типа
val greeting = "Привет, Android!"
val count = greeting.length
```

## Структура курса

| Раздел | О чём | Часы |
|---|---|---|
| 1. Основы языка (типы, ветвление, циклы, массивы, методы) | Фундамент программирования | 16 |
| 2. Введение в ООП (+ Context/Intent, Generics) | Классы, наследование, первое знакомство с Android-понятиями | 16 |
| 3. Android-разработка (UI, жизненный цикл, потоки, сервисы, фрагменты, графика) | Собственно мобильная разработка | 48 |
| 4. Алгоритмы и структуры данных (списки, деревья, сортировки, SQLite, хеширование, криптография) | Инструменты, на которых строится логика приложения | 48 |
| 5. Серверная часть (HTTP, REST, облачные платформы, Material Design) | Как приложение общается с внешним миром | — |

Разделы идут именно в этом порядке не случайно: раздел 3 (Android) невозможно понять без ООП из раздела 2, а раздел 4 (структуры данных) постоянно опирается на Android-примеры («список в Android», «SQLite-запрос в Android») из раздела 3.

## Инструменты

- **JDK** (Java Development Kit) — обязателен, на нём работает и Java, и Kotlin.
- **Android Studio** — официальная среда разработки для Android (включает эмулятор устройства — не обязательно иметь физический телефон для учёбы).
- **Kotlin-плагин** — идёт в Android Studio из коробки, отдельно ставить не нужно.
- **Git** — по желанию, для сохранения версий своих проектов, пригодится в любом будущем проекте.

Каждая лекция курса сопровождается практикой — по официальным номерам рабочей программы (ПР3.01–ПР3.04, ЛР3.01–ЛР3.02, см. [[Колледж/Группы/КСП 09.02.07.39/JAWA/Навигатор|Навигатор]]).
