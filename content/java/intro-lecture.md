# Введение в курс

## Как читать курс и не пытаться запомнить всё сразу

Цель курса — научиться объяснять, как программа получает данные, принимает решения, повторяет действия и работает с объектами. Мобильный интерфейс появится позже: кнопка сама по себе не заменяет алгоритм, а красивый экран не исправляет неверный расчёт.

**Задача** описывает желаемый результат. **Решение** задаёт шаги. **Код** записывает эти шаги на языке. **Проверка** показывает, совпало ли поведение с ожиданием. Если результат неверен, возвращайся к тому этапу, где возникло расхождение.

## Общая форма работы над программой

Это учебный маршрут, а не синтаксис Java:

```text
условие задачи → пример на бумаге → алгоритм → код
→ прогноз вывода → запуск → сравнение → исправление
```

Не начинай со случайного поиска похожего файла. Сначала придумай маленький пример, для которого ответ понятен без программы. Тогда будет с чем сравнить запуск.

## Пример: что проверяем в первой программе

```java
public class CourseDemo {
    public static void main(String[] args) {
        String name = "Анна";
        int completed = 2;
        System.out.println(name);
        System.out.println(completed + 1);
    }
}
```

Файл — CourseDemo.java. После компиляции и запуска ожидаются две строки:

```text
Анна
3
```

| Запись | Роль | Важная проверка |
|---|---|---|
| `String name = "Анна";` | Сохранить текст в локальной переменной | Кавычки обозначают значение, name — выбранное имя |
| `int completed = 2;` | Сохранить целое число | Это не строка "2" |
| `println(name)` | Показать сохранённый текст | Само объявление name ещё ничего не печатает |
| `println(completed + 1)` | Вычислить сумму и показать её | Значение completed остаётся 2: присваивания обратно нет |

Эта последняя деталь важна с первой темы. Вычисление нового значения и изменение переменной — разные действия. Чтобы сохранить 3, нужна инструкция `completed = completed + 1;`.

## Какие названия можно выбирать

CourseDemo — имя собственного класса, name и completed — имена переменных. Ты можешь назвать их по-другому, согласованно исправив обращения. Слова public, class, static, void и int задаёт Java. Метод println уже объявлен в библиотеке; его имя просто так не меняется.

Имя публичного класса в привычной файловой форме совпадает с именем файла. Если класс назвать MyCourse, файл будет MyCourse.java, а команда запуска — `java MyCourse`. Названия примеров в лекциях помогают отличать программы и не являются обязательными именами твоих проектов.

## JDK, JVM и IDE: три разных назначения

**JDK** — набор инструментов разработки Java; для наших опытов особенно важны javac и java. **JVM** — виртуальная машина, выполняющая подготовленный Java-байт-код. **IDE** — среда, где удобно редактировать, запускать и отлаживать проект.

Редактор может показывать красивую подсветку, даже если запуск ещё не настроен. Наличие файла `.java` не доказывает наличие JDK. Ошибка «команда javac не найдена» чаще относится к установке или настройке инструментов, а не к арифметике в программе.

В онлайн-среде часть этих действий выполняет сервер. Поэтому нужно учитывать ограничения сервиса: имя класса Main, способ ввода данных, время выполнения. Пример с ожидающим Scanner может казаться «зависшим», хотя он просто ждёт ввод.

## Кнопка Run объединяет несколько действий

В обычном проекте сначала проверяется и компилируется исходник, затем запускается точка входа. IDE скрывает команды за кнопкой, но различие этапов остаётся. Если компилятор остановился, не ищи ещё не полученный вывод в консоли.

Привычные команды из папки файла:

```text
javac -encoding UTF-8 CourseDemo.java
java CourseDemo
```

Расширение `.java` указываем javac как часть имени исходного файла. Во второй команде выбираем имя класса, поэтому не дописываем `.class`. Это показанная здесь двухшаговая схема; у современных JDK есть и другие способы запуска.

## Как пользоваться подробной лекцией

Сначала прочитай общую форму. В ней подписи обозначают места для твоих имён и значений. Затем изучи конкретный пример. Перед инфографикой расположен именно тот фрагмент, который она объясняет. Сверь состояние до и после каждой строки.

Легенда цветов помогает различать роли, но смысл не определяется одним цветом: поле и параметр находятся в группе данных, а различаются местом объявления. В вопросе «почему стало 3?» ищи вычисление или присваивание, а не оттенок текста.

При первом проходе не нужно помнить весь справочник. Нужно уметь вернуться к объявлению, найти нужную строку и проверить свою гипотезу маленьким запуском.

## Как разбирать сообщение об ошибке

1. Прочитай первое относящееся к твоему файлу сообщение.
2. Найди указанную строку и проверь также строку перед ней.
3. Определи, что не подошло: имя, тип, скобка, инструкция, настройка запуска.
4. Исправь одну причину и повтори проверку.

После пропущенной скобки компилятор иногда показывает много последствий. Исправление самой первой причины может убрать сразу несколько сообщений. Это не повод менять весь файл наугад.

## Как задавать вопрос и проверять чужой пример

Хороший вопрос содержит ожидаемый результат, фактический вывод, точный текст ошибки и небольшой код, который её воспроизводит. Фраза «не работает» не показывает, на каком этапе возникла проблема.

Код из интернета или подсказки можно использовать для изучения, но сначала выясни имена переменных, входные данные и последовательность действий. Затем поменяй значения и объясни новый результат. Если после переименования переменной всё перестало работать, проверь согласованность обращений.

## Java и Kotlin в этом маршруте

Основные примеры этой части написаны на Java. Когда синтаксис Java понятен, сравнение с Kotlin помогает увидеть ту же идею в другой записи. Разница в количестве строк ещё не объясняет, почему решение корректно.

Консольные Java-программы запускаются на JVM. Для Android код проходит сборку в DEX и работает с ART и Android API. Поэтому сначала мы осваиваем общие конструкции и объекты, а затем связываем их с жизненным циклом мобильного приложения.

## Самостоятельный первый шаг

Создай свою программу с именем класса StudyCard. Сохрани имя предмета и число завершённых заданий в двух переменных. Выведи их, затем отдельно выведи число «на одно задание больше». Проверь, изменилось ли исходное число без присваивания.

Порядок сдачи работ, критерии оценивания, сроки и организационные требования уточняй у своего преподавателя. Учебные рекомендации на странице не устанавливают новые правила допуска или экзамена.
