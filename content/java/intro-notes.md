# Введение в курс — под запись

Маршрут: задача → пример на бумаге → алгоритм → код → прогноз → запуск → проверка. Учись объяснять изменение данных, а не только воспроизводить текст файла.

**JDK** — инструменты разработки; **JVM** — виртуальная машина для Java-байт-кода; **IDE** — среда редактирования, запуска и отладки. Наличие редактора ещё не доказывает, что JDK установлен и настроен.

## Обычный двухшаговый запуск

```text
javac -encoding UTF-8 ИмяКласса.java
java ИмяКласса
```

Это шаблон команды: замени имя на реальное. Класс, файл и команда запуска должны быть согласованы. После изменения исходника снова выполняется компиляция.

## Как проверять пример

Сначала предскажи вывод, затем запусти. Измени одно значение или имя и объясни новый результат. Сообщая об ошибке, приложи небольшой код, ожидаемый результат и точный текст сообщения.

## Проверь себя

1. Что делает javac и что делает java?
2. Почему красивой подсветки недостаточно для работающей программы?
3. Почему print и присваивание — разные действия?
4. Как понять, на каком этапе возникла ошибка?

Порядок сдачи, сроки, правила оценивания и требования к экзамену уточняй у преподавателя. Этот конспект не устанавливает новых условий допуска.
