# 0. Введение в курс — под запись

## 1. О курсе

**Курс:** МДК.01.03 «Разработка мобильных приложений» (профессиональный модуль ПМ.01). Объём — 172 часа. Итоговая аттестация — экзамен.

**К концу курса вы должны уметь:**

1. писать программы на Java: типы данных, условия, циклы, массивы, методы;
2. проектировать код в объектно-ориентированном стиле: классы, наследование, полиморфизм;
3. разрабатывать интерфейс Android-приложения и обрабатывать действия пользователя;
4. хранить данные в базе SQLite и получать данные с сервера;
5. применять основные структуры данных и алгоритмы: списки, деревья, сортировки, хеширование.

## 3. Два языка

**Основной язык курса — Java.** Причины:

1. программа курса, практические работы и экзамен составлены по Java;
2. огромная часть существующих Android-приложений написана на Java, и их код нужно уметь читать и дорабатывать;
3. в Java всё записывается явно, поэтому на ней лучше видно, как устроена программа.

**Kotlin** показывается параллельно: тот же код, записанный короче. Kotlin работает на той же виртуальной машине и полностью совместим с Java, поэтому это не второй курс, а вторая запись того же самого.

Одна и та же программа:

```java
// Java
public class Main {
    public static void main(String[] args) {
        String greeting = "Привет, Android!";
        int count = greeting.length();
        System.out.println(count);
    }
}
```

```kotlin
// Kotlin
fun main() {
    val greeting = "Привет, Android!"
    val count = greeting.length
    println(count)
}
```

Обе выводят `16`. В Kotlin тип переменной не записан, но он есть: компилятор определяет его сам до запуска. Типизация остаётся статической.

## 4. Инструменты

**JDK** (Java Development Kit) — набор инструментов разработчика на Java. В него входят компилятор `javac` и виртуальная машина JVM. Без JDK программу на Java нельзя ни собрать, ни запустить.

**IDE** (Integrated Development Environment, среда разработки) — программа для написания кода: редактор с подсветкой и подсказками, кнопка запуска, отладчик.

**Что используем в курсе:**
- сейчас — онлайн-компилятор в браузере (ничего устанавливать не нужно);
- дома и на практических — IntelliJ IDEA Community или Visual Studio Code с расширением для Java;
- в разделе про Android — Android Studio.

Сообщение об ошибке нужно читать: в нём указаны номер строки и то, чего ожидал компилятор. Пример: `error: ';' expected` — в указанной строке пропущена точка с запятой.

## 6. Правила курса

1. **Конспект ведётся в тетради от руки.** Всё, что диктуется под запись, должно быть в тетради. Файл «Под запись» — для сверки, а не вместо конспекта.
2. **Каждая лекция начинается с опроса** по вопросам «Проверь себя» из предыдущей темы.
3. **Практическая работа считается сданной только после защиты.** На защите нужно показать работающую программу и объяснить любую её строку.
4. **Код, который студент не может объяснить, не засчитывается**, откуда бы он ни взялся: от соседа, из интернета или от нейросети.
5. **Вариант** в практических работах определяется по номеру в журнале.
6. **Пропущенная тема** восстанавливается самостоятельно по файлам курса; практическая по ней сдаётся в общем порядке.
7. **Допуск к экзамену** — все практические и лабораторные работы сданы.

Экзамен: банк из 88 вопросов трёх уровней сложности. Вопросы «Проверь себя» после каждой лекции — подготовка к нему.
