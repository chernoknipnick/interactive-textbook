# 00. Обзор языков программирования — под запись

> МДК.01.03 «Разработка мобильных приложений». Это то, что должно быть в тетради после пары. Определения нужно знать и уметь объяснить своими словами.

## 1. Язык программирования и машинный код

**Язык программирования** — формальный язык для записи программ: набор правил, по которым человек описывает компьютеру, что нужно сделать.

**Машинный код** — команды в виде чисел, которые процессор выполняет напрямую. У каждого типа процессора машинный код свой.

Процессор понимает только машинный код. Текст программы на любом языке нужно перевести.

Универсального языка нет. Каждый язык — компромисс:

| Что получаем | Чем платим | Пример |
|---|---|---|
| Скорость и контроль над памятью | Писать долго, ошибиться легко | C, C++ |
| Писать быстро и коротко | Программа работает медленнее | Python |
| Одна программа на любом устройстве | Нужна программа-посредник | Java, Kotlin |

## 2. Три пути от текста к работающей программе

```
1) текст программы ──[компилятор]──► машинный код ──► процессор

2) текст программы ──[интерпретатор]──► процессор

3) текст программы ──[компилятор]──► байт-код ──[виртуальная машина]──► процессор
```

**Компилятор** — программа, которая переводит весь текст программы в машинный код заранее, до запуска. Результат — исполняемый файл.
Плюс: программа работает быстро. Минус: под каждую систему и каждый процессор нужна своя сборка.
Примеры языков: C, C++, Rust, Go.

**Интерпретатор** — программа, которая читает текст программы и выполняет его по одной команде прямо во время запуска. Исполняемый файл не создаётся.
Плюс: один и тот же файл с кодом работает везде, где установлен интерпретатор; изменил код — сразу запустил. Минус: работает медленнее; ошибка обнаруживается только тогда, когда выполнение до неё дошло.
Примеры языков: Python, JavaScript, PHP.

**Байт-код** — промежуточный код, не привязанный к конкретному процессору. Процессор его не понимает; его выполняет виртуальная машина.

**Виртуальная машина** — программа, которая выполняет байт-код на конкретном устройстве. Виртуальная машина Java называется **JVM** (Java Virtual Machine).

Путь программы на Java:

```
файл .java ──[javac]──► файл .class (байт-код) ──► JVM ──► процессор
```

Так работают Java, Kotlin, C#.

**JIT-компиляция** (just-in-time) — перевод часто выполняемых участков байт-кода в машинный код прямо во время работы программы. За счёт этого Java работает почти так же быстро, как компилируемые языки.

| | Компилятор | Интерпретатор | Байт-код + ВМ |
|---|---|---|---|
| Когда перевод | Заранее, один раз | При каждом запуске | Часть заранее, часть при запуске |
| Скорость работы | Высокая | Низкая | Близка к высокой |
| Работает на разных системах | Нет, нужна пересборка | Да, если есть интерпретатор | Да, если есть виртуальная машина |
| Когда видны ошибки записи | До запуска | Во время работы | До запуска |
| Языки | C, C++, Rust, Go | Python, JavaScript, PHP | **Java, Kotlin**, C# |

## 3. Типизация

**Тип данных** определяет, какие значения можно хранить и какие операции с ними можно выполнять. Примеры: целое число, дробное число, строка, логическое значение (истина/ложь).

**Когда проверяются типы:**

**Статическая типизация** — тип переменной задаётся в коде и проверяется до запуска программы. Ошибка типа не даст программе запуститься. Языки: Java, Kotlin, C++.

**Динамическая типизация** — тип определяется во время работы программы; одна переменная может в разные моменты хранить значения разных типов. Ошибка типа обнаруживается только при выполнении той строки, где она есть. Языки: Python, JavaScript, PHP.

**Насколько строго проверяются типы:**

**Строгая (сильная) типизация** — язык не преобразует значения одного типа в другой молча; несовместимые типы дают ошибку. Языки: Java, Kotlin, Python.

**Слабая типизация** — язык сам, без предупреждения, преобразует типы, чтобы операция выполнилась. Языки: JavaScript, PHP.

| | **Строгая** | **Слабая** |
|---|---|---|
| **Статическая** | **Java, Kotlin**, C# | C, C++ |
| **Динамическая** | Python | JavaScript, PHP |

Примеры с пары:

```java
int age = "восемнадцать";   // Java: программа не запустится вообще
```

```python
age = "восемнадцать"
print(age + 1)              # Python: запустится и упадёт на этой строке
```

```javascript
"5" * "2"   // 10     JavaScript: молча преобразует типы
"5" + 2     // "52"
```

## 4. Парадигмы программирования

**Парадигма программирования** — подход к тому, как организовать код программы.

1. **Процедурная** — программа есть последовательность команд, собранных в функции. Пример: C.
2. **Объектно-ориентированная (ООП)** — программа есть набор объектов, каждый из которых хранит свои данные и умеет выполнять свои действия. Примеры: Java, Kotlin, C#.
3. **Функциональная** — программа есть цепочка функций, которые получают данные и возвращают новые, ничего не изменяя. Пример: Haskell; элементы есть в Kotlin.
4. **Декларативная** — программист описывает, *что* нужно получить, а не *как* это сделать. Пример: SQL.

Большинство современных языков поддерживают несколько парадигм. Говорят об основной.

## 6. Java и Kotlin

**Java** — 1995 год, компания Sun Microsystems. Принцип: «Write once, run anywhere» — «написал один раз, запускай где угодно».

**Kotlin** — представлен в 2011 году, компания JetBrains. Компилируется в тот же байт-код, что и Java, и полностью с ней совместим.

**2019 год** — Google объявила Kotlin приоритетным языком разработки под Android.

Оба языка: байт-код + виртуальная машина; статическая строгая типизация; основная парадигма — ООП.

```
Main.java ──[javac]────┐
                       ├──► байт-код (.class) ──► виртуальная машина
Main.kt   ──[kotlinc]──┘
```
