# Обзор языков программирования — под запись

**Язык программирования** задаёт допустимые записи и их смысл. **Алгоритм** — последовательность действий для решения задачи. **Программа** записывает решение на выбранном языке. **Компилятор** переводит исходник; **среда выполнения** обеспечивает выполнение подготовленного кода.

## Общая форма маршрута

```text
задача → алгоритм → исходный код → подготовка → выполнение → проверка
```

Для привычного Java-проекта: `.java → javac → .class → JVM`. Для Android сборка получает DEX, который используется средой ART. Это не запуск обычного .class настольной командой java.

**Статическая типизация** позволяет проверять многие операции по типам до выполнения. **Динамическая** переносит больше таких проверок на время выполнения. Вывод типа компилятором не делает язык динамическим.

Названия «сильная» и «слабая» типизация неоднозначны: уточняй конкретные правила преобразований. В Java `"Билетов: " + 3` допустимо, а `int count = "три"` — нет.

## Пример внутри main

```java
int price = 120;
int count = 3;
System.out.println(price * count);
```

Вывод — 360. price и count можно согласованно переименовать. int, знаки синтаксиса и имя готового println не заменяются произвольными словами.
