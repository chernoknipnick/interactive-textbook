# Циклы

## Цикл — повторение с проверяемым правилом

Если нужно вывести три числа, можно написать три команды. Но для тысячи чисел удобнее описать действие один раз и задать правило повторения. **Итерация** — одно выполнение тела. Условие определяет, нужно ли очередное выполнение.

Цикл не «понимает, сколько достаточно» по смыслу задачи. Ты задаёшь начальное состояние, условие и изменения. Ошибка в любом из этих мест может дать лишний проход или бесконечное повторение.

## Общие формы трёх циклов

Это шаблоны, а не готовые программы:

```text
while (логическоеУсловие) {
    действия;
}

for (начальныеДействия; логическоеУсловие; действияПослеИтерации) {
    телоЦикла;
}

do {
    действия;
} while (логическоеУсловие);
```

Имена и конкретные выражения зависят от задачи. Слова while, for, do и знаки синтаксиса задаёт Java. У do-while после круглой скобки в конце есть `;`; у обычного while точка с запятой сразу после условия создаёт пустое тело, что часто оказывается ошибкой.

## Полный пример: сумма от одного до трёх

```java
public class LoopDemo {
    public static void main(String[] args) {
        int sum = 0;
        for (int number = 1; number <= 3; number++) {
            sum += number;
            System.out.println(sum);
        }
        System.out.println("Итог: " + sum);
    }
}
```

Файл LoopDemo.java. Вывод:

```text
1
3
6
Итог: 6
```

## Читаем заголовок не слева направо один раз, а по порядку исполнения

`int number = 1` выполняется один раз. Затем проверяется `number <= 3`. Если true, выполняется тело. Только после тела выполняется number++. Потом программа возвращается к проверке условия, а не к повторному объявлению number.

`sum` объявлена **до** цикла, поэтому сохраняет накопленный результат между итерациями и доступна после цикла. `number` объявлена в заголовке for и за пределами этого цикла недоступна. Это различие областей видимости, а не особое свойство имён sum и number.

`sum += number` для этих int-значений означает прибавление текущего number к прежней сумме и сохранение результата. Ноль выбран потому, что добавление нуля не меняет сумму. Для произведения начальное значение обычно 1, а не 0.

| Перед проверкой number | Условие | sum до тела | sum после тела | Следующее действие |
|---:|---|---:|---:|---|
| 1 | true | 0 | 1 | number становится 2 |
| 2 | true | 1 | 3 | number становится 3 |
| 3 | true | 3 | 6 | number становится 4 |
| 4 | false | 6 | Тело не выполняется | Выход к итоговому println |

Проверок четыре, а выполнений тела три. Последняя ложная проверка нужна, чтобы выйти.

## Тот же алгоритм через while

```java
int sum = 0;
int number = 1;
while (number <= 3) {
    sum += number;
    number++;
}
```

Вставляй этот вариант **вместо** предыдущего расчёта внутри main, а не рядом с повторным объявлением sum в той же области. Результат тот же, но начальное значение и изменение счётчика расположены отдельно от условия.

Если убрать number++, условие для положительных маленьких значений останется истинным и сумма начнёт расти при бесконечном повторении. Если поставить sum = 0 внутрь тела, сумма будет забываться перед каждым прибавлением.

## Зачем нужен do-while

Он сначала выполняет тело и только потом проверяет продолжение. Например, ввод нужно предложить хотя бы один раз. Но это не означает, что любая программа с do-while всегда корректно обработает неверный тип ввода: проверки Scanner нужно писать отдельно.

Для предсказания поведения возьми исходное значение, при котором условие ложно. while выполнит тело ноль раз, do-while — один. Так проще увидеть различие без длинного примера.

## break, continue и точка продолжения

break выходит из ближайшего цикла. continue завершает текущую итерацию ближайшего цикла. У for после continue выполняется действие изменения, затем новая проверка. У while управление возвращается к условию: если нужное изменение стояло ниже continue, оно может быть пропущено.

Безметочные break и continue во вложенных циклах относятся к ближайшему циклу. В Java есть и варианты с метками, но для начальных задач достаточно этого случая.

## Как считать число повторений

У `for (int index = 0; index < 5; index++)` тело выполняется для 0, 1, 2, 3, 4 — пять раз. При `<= 5` добавится значение 5 — получится шесть раз. При старте с 1 и `<= 5` снова пять раз, но набор значений другой.

Вложенные циклы перемножают количества проходов только когда число выполнений внутреннего одинаково для каждого прохода внешнего. Если внутренняя граница зависит от внешнего счётчика, нужна отдельная трассировка, а не слепое умножение.

## Переход к самостоятельной задаче

Сначала измени границу 3 на 5: сумма должна стать 15. Затем убери промежуточный вывод и оставь только итог. Потом посчитай не сумму всех чисел, а количество чётных: отдельный count начинается с 0 и увеличивается внутри if.

Перед запуском всегда перечисляй первые два и последний допустимый счётчик. Затем добавляй первую недопустимую проверку. Такой маленький список часто сразу показывает ошибку на единицу.

Для закрепления объясни, почему `for (int number = 10; number > 0; number -= 3)` использует значения 10, 7, 4, 1 и заканчивается после получения -2.

## Справочник и дополнительные упражнения по теме

## 1. Цикл `while`

**Цикл** — конструкция, которая многократно выполняет один и тот же блок кода.
**Тело цикла** — блок кода, который повторяется.
**Итерация** — одно выполнение тела цикла.

**Цикл `while`** (с предусловием) повторяет тело, пока условие истинно:

```text
while (условие) {
    тело цикла
}
```

Условие проверяется **перед** каждой итерацией. Если оно ложно с самого начала, тело не выполнится ни разу.

```java
int money = 0;
int month = 0;

while (money < 50000) {
    money += 8000;
    month++;
}
System.out.println("Месяцев: " + month);     // 7
```

**Чтобы цикл завершился, нужны три вещи:**
1. **начальное значение** переменной, от которой зависит условие (до цикла);
2. **условие** продолжения;
3. **изменение** этой переменной в теле цикла.

**Бесконечный цикл** — цикл, который не завершается сам по предусмотренным путям; например, условие остаётся истинным и нет выхода через break или return. Причины: переменная в условии не изменяется в теле; изменяется не в ту сторону; после условия стоит `;`.

## 2. Цикл `for`

**Цикл `for`** (со счётчиком):

```text
for (инициализация; условие; изменение) {
    тело цикла
}
```

1. **инициализация** — выполняется один раз перед циклом;
2. **условие** — проверяется перед каждой итерацией;
3. **изменение** — выполняется после каждой итерации.

Порядок выполнения: инициализация → (условие → тело → изменение) → (условие → тело → изменение) → … → условие ложно → выход.

```
for ( int i = 1 ;  i <= 5 ;  i++ ) {
        ①            ②        ④
    System.out.println(i);     ③
}
```

Трассировка:

| Шаг | `i` | `i <= 5` | Что выведено | После `i++` |
|---|---|---|---|---|
| 1 | 1 | true | 1 | 2 |
| 2 | 2 | true | 2 | 3 |
| 3 | 3 | true | 3 | 4 |
| 4 | 4 | true | 4 | 5 |
| 5 | 5 | true | 5 | 6 |
| 6 | 6 | **false** | — | выход |

Счётчик цикла обычно называют `i` (затем `j`, `k`). Переменная, объявленная в заголовке `for`, существует только внутри цикла.

**Два стандартных заголовка для «повторить n раз»:**
- `for (int i = 0; i < n; i++)` — счётчик от 0 до n−1 (основной вариант: так нумеруются элементы массивов и символы строк);
- `for (int i = 1; i <= n; i++)` — счётчик от 1 до n.

**Ошибка на единицу** — цикл выполняется на одну итерацию больше или меньше, чем нужно. Чаще всего из-за путаницы `<` и `<=` или начала с 0 вместо 1.

```java
for (int i = 0; i < 5; i++)       // 0 1 2 3 4     — 5 раз
for (int i = 1; i <= 5; i++)      // 1 2 3 4 5     — 5 раз
for (int i = 0; i <= 5; i++)      // 0 1 2 3 4 5   — 6 раз
for (int i = 10; i >= 0; i -= 5)  // 10 5 0        — обратный отсчёт
for (int i = 0; i < 10; i += 2)   // 0 2 4 6 8     — с шагом 2
```

## 3. Цикл `do-while`

**Цикл `do-while`** (с постусловием):

```text
do {
    тело цикла
} while (условие);
```

Условие проверяется **после** каждой итерации, поэтому тело выполняется **хотя бы один раз**.
После `while (условие)` ставится точка с запятой.
Типичное применение — повторять ввод, пока данные некорректны.

```java
int age;                       // объявлена до цикла, чтобы её видело условие
do {
    System.out.print("Введите возраст (0-120): ");
    age = scanner.nextInt();
} while (age < 0 || age > 120);
```

## 4. Какой цикл выбрать

| Ситуация | Цикл |
|---|---|
| Число повторений известно заранее; нужен счётчик | `for` |
| Число повторений неизвестно; повторять, пока выполняется условие | `while` |
| То же, но тело должно выполниться хотя бы один раз | `do-while` |

Любой цикл можно переписать через любой другой; выбирают тот, с которым код понятнее.

## 5. `break` и `continue`

**`break`** — немедленно завершает цикл; выполнение продолжается с инструкции после цикла.
**`continue`** — завершает текущую итерацию и переходит к следующей (в `for` — к изменению счётчика).
Безметочные break и continue относятся к ближайшему циклу. В Java есть также формы с метками, которые здесь не используются.

```java
for (int i = 1; i <= 10; i++) {
    if (i % 2 != 0) {
        continue;              // нечётные пропускаем
    }
    System.out.print(i + " "); // 2 4 6 8 10
}
```

## 6. Типовые алгоритмы с циклом

1. **Накопление суммы:** накопитель создаётся до цикла (`int sum = 0;`), изменяется в цикле (`sum += …;`), используется после цикла. Для произведения начальное значение — 1.
2. **Подсчёт по условию:** счётчик до цикла (`int count = 0;`), в цикле `if (условие) { count++; }`.
3. **Разбор числа на цифры:** `while (n > 0) { цифра = n % 10; n /= 10; }`.
4. **Поиск (флаг):** `boolean found = false;` до цикла; в цикле при совпадении `found = true; break;`.

```java
int sum = 0;                           // сумма чисел от 1 до 100
for (int i = 1; i <= 100; i++) {
    sum += i;
}                                      // 5050
```

```java
int count = 0;                         // сколько чисел от 1 до 100 кратно 7
for (int i = 1; i <= 100; i++) {
    if (i % 7 == 0) {
        count++;
    }
}                                      // 14
```

```java
int n = 1234;                          // сумма цифр числа
int digitSum = 0;
while (n > 0) {
    digitSum += n % 10;
    n /= 10;
}                                      // 10
```

**Обход строки:** `for (int i = 0; i < s.length(); i++) { char c = s.charAt(i); … }`
`s.charAt(i)` — символ с номером `i`; номера идут от 0 до `s.length() - 1`.

## 7. Вложенные циклы

**Вложенный цикл** — цикл внутри тела другого цикла. На каждую итерацию внешнего цикла внутренний выполняется полностью.
Если число проходов внутреннего цикла одинаково на каждой итерации внешнего, общее количество выполнений внутреннего тела равно произведению. Для зависимых границ нужна отдельная трассировка.
Счётчики вложенных циклов называют по-разному: `i` — внешний, `j` — внутренний.

```java
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        System.out.print(i * j + "\t");
    }
    System.out.println();
}
```

```
1	2	3
2	4	6
3	6	9
```

## 8. Ошибки, которые компилятор не замечает

| Что написано | Что происходит |
|---|---|
| переменная условия не меняется в теле `while` | бесконечный цикл |
| `while (x < 10);` при неизменном x < 10 | бесконечное повторение пустого тела |
| `i--` вместо `i++` | цикл идёт не в ту сторону |
| `<=` вместо `<` | лишняя итерация |
| накопитель произведения начинается с 0 | результат всегда 0 |

Если непонятно, что делает цикл, — составить таблицу трассировки.
