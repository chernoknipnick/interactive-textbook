# 1.2.2. Конструкторы и их перегрузка. Инкапсуляция — под запись

> МДК.01.03 «Разработка мобильных приложений». Это то, что должно быть в тетради после пары.

## 1. Конструктор

**Конструктор** — специальный блок кода в классе, который выполняется при создании объекта через `new` и задаёт начальные значения полей.

```java
class Student {
    String name;
    int age;

    Student(String n, int a) {     // конструктор
        name = n;
        age = a;
    }
}

Student anna = new Student("Анна", 17);    // вызов конструктора
```

**Отличия конструктора от метода:**
1. имя конструктора совпадает с именем класса;
2. у конструктора **нет типа возврата**, даже `void`;
3. конструктор вызывается только через `new`, один раз для каждого объекта.

Порядок при `new`: память под объект → значения по умолчанию → тело конструктора → ссылка на объект.

Если перед конструктором написать `void`, он станет обычным методом.

## 2. `this`

**`this`** — ссылка на текущий объект: тот, который создаётся конструктором или у которого вызван метод.
`this.name` — поле объекта; `name` — параметр (если параметр с таким именем есть).

Стандартная форма конструктора: параметры называются как поля, присваивание — через `this`:

```java
Student(String name, int age) {
    this.name = name;
    this.age = age;
}
```

**Ошибка:** `name = name;` без `this` присваивает параметр самому себе; поле не меняется, компилятор ошибку не показывает.

## 3. Конструктор по умолчанию

**Конструктор по умолчанию** — конструктор без параметров с пустым телом. Java добавляет его автоматически, **только если в классе не объявлено ни одного конструктора**.
Как только в классе объявлен хотя бы один конструктор, конструктор по умолчанию не создаётся.

## 4. Перегрузка конструкторов

**Перегрузка конструкторов** — несколько конструкторов в одном классе с разными списками параметров. Java выбирает конструктор по аргументам в `new`.

**`this(...)`** — вызов другого конструктора того же класса. Должен быть **первой инструкцией** в конструкторе.
Приём: один «главный» конструктор со всеми параметрами выполняет присваивания, остальные вызывают его через `this(...)` и подставляют значения по умолчанию.

`this.поле` — обращение к полю; `this(...)` — вызов конструктора.

```java
Student(String name, int age, double averageMark) {    // главный
    this.name = name;
    this.age = age;
    this.averageMark = averageMark;
}

Student(String name, int age) {
    this(name, age, 0.0);
}

Student() {
    this("Без имени", 0);
}
```

## 5. Инкапсуляция

**Инкапсуляция** — сокрытие данных объекта: поля закрыты от прямого доступа извне класса, работа с ними идёт через методы класса, которые могут проверять значения.

**Модификаторы доступа**

| Модификатор | Где доступно |
|---|---|
| `private` | только внутри своего класса |
| (без модификатора) | внутри своего пакета |
| `protected` | внутри пакета и в классах-наследниках (тема 1.2.4) |
| `public` | везде |

**Правило:** поля — `private`, методы для работы с ними — `public`.

**Геттер** — метод, возвращающий значение поля: `public int getAge() { return age; }`
**Сеттер** — метод, устанавливающий значение поля, обычно с проверкой:

```java
public void setAge(int age) {
    if (age < 0 || age > 120) {
        System.out.println("Ошибка: недопустимый возраст");
        return;                      // поле не меняется
    }
    this.age = age;
}
```

Имена: `get` + имя поля с большой буквы; для `boolean` — `is`: `isActive()`. Сеттер: `set` + имя поля.
Поле только для чтения: геттер есть, сеттера нет.
Конструктор может вызывать сеттеры, чтобы проверка работала и при создании объекта.

**Класс целиком:**

```java
class Student {
    private String name;
    private int age;

    Student(String name, int age) {
        this.name = name;
        setAge(age);
    }

    public String getName() {
        return name;
    }

    public int getAge() {
        return age;
    }

    public void setAge(int age) {
        if (age < 0 || age > 120) {
            System.out.println("Ошибка: недопустимый возраст " + age);
            return;
        }
        this.age = age;
    }
}
```

## 6. Сообщения об ошибках

| Сообщение | Причина |
|---|---|
| `constructor Student in class Student cannot be applied to given types` | нет конструктора с такими параметрами (или перед конструктором стоит `void`) |
| `call to this must be first statement in constructor` | `this(...)` стоит не первой строкой |
| `age has private access in Student` | обращение к `private`-полю извне класса |
| `invalid method declaration; return type required` | имя конструктора не совпадает с именем класса |
| (сообщения нет, поля пустые) | `name = name;` без `this` |
