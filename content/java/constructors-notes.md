# 1.2.2 Конструкторы — Под запись

#java #ооп #конспект


## Определения

**Конструктор** — специальное объявление класса, задающее действия при инициализации нового экземпляра. Его имя совпадает с именем класса, тип результата не пишется.

**Перегрузка конструкторов** — несколько конструкторов одного класса с разными списками параметров.

**`this.field`** — обращение к полю текущего объекта; **`this(...)`** — вызов другого конструктора того же класса.

**Конструктор по умолчанию** предоставляется компилятором, если в обычном классе не объявлен ни один конструктор.

**`private`** ограничивает прямой доступ к члену класса; в наших отдельных учебных классах обращаться к закрытому полю можно из кода его собственного класса.

**Геттер** возвращает значение свойства. **Сеттер** предлагает изменить свойство; необходимость сеттера и проверки определяются правилами класса.

## Короткий образец

```java
class Student {
    private String name;
    Student(String name) {
        this.name = name;
    }
    public String getName() {
        return name;
    }
}
```

`new Student("Анна")` передаёт имя конструктору. Слева в `this.name = name` поле, справа параметр. `name = name` не заполняет поле. `void Student(...)` был бы обычным методом.

Свой конструктор отменяет автоматическое добавление конструктора по умолчанию. Дополнительный конструктор может вызвать основной через `this(...)`; в наших примерах такой вызов ставим первым. Современные версии Java имеют более гибкие правила, но для этого курса они не нужны.

Недопустимые данные следует явно отклонять. В полном примере энергия вне 0–100 вызывает исключение. `private` запрещает прямое присваивание из другого отдельного класса; разрешённые действия задают методы. Не каждому полю нужен сеттер.
