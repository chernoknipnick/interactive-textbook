## Задание 1. Повторение с помощью циклов — 15 минут

В классе `LoopWarmup` замените пробный вывод таким кодом:

```java
for (int number = 1; number <= 5; number++) {
    System.out.println(number);
}
```

Разберём заголовок по частям:

| Часть | Что происходит |
|---|---|
| `int number = 1` | Счётчик создаётся один раз перед началом цикла |
| `number <= 5` | Перед каждым повторением проверяется условие |
| `number++` | После тела цикла счётчик увеличивается на один |

Программа выведет числа от 1 до 5, каждое с новой строки. После вывода числа 5 счётчик станет равен 6. Условие окажется ложным, цикл завершится.

Добавьте ниже второй цикл:

```java
int remaining = 5;
while (remaining > 0) {
    System.out.println("Осталось: " + remaining);
    remaining--;
}
```

Здесь переменная создаётся перед циклом, условие записано в скобках после `while`, изменение переменной находится внутри тела. Если забыть `remaining--`, значение останется равным 5 и цикл не завершится сам.

Самостоятельно:

1. Измените первый цикл так, чтобы он выводил числа от 1 до 10.
2. Добавьте цикл, который выводит только чётные числа от 2 до 20. Можно увеличивать счётчик на 2: `number += 2`.
3. До запуска предскажите, сколько раз выполнится цикл `for (int number = 0; number < 5; number++)`. Запишите ответ и проверьте.

## Задание 2. Случайные числа — 10 минут

В файле `RandomDemo.java` напишите:

```java
import java.util.Random;

public class RandomDemo {
    public static void main(String[] args) {
        Random random = new Random();
        int minValue = 10;
        int maxValue = 15;

        for (int attempt = 1; attempt <= 10; attempt++) {
            int value = random.nextInt(maxValue - minValue + 1) + minValue;
            System.out.println(value);
        }
    }
}
```

`import` подключает имя готового класса из стандартной библиотеки. `new Random()` создаёт генератор случайных чисел. Здесь достаточно пользоваться готовым генератором; устройство объектов разберём позже.

Метод `nextInt(6)` может вернуть 0, 1, 2, 3, 4 или 5. Верхняя граница 6 в результат не входит.

Чтобы получить числа от 10 до 15 включительно:

1. Считаем количество допустимых целых значений: `15 - 10 + 1 = 6`.
2. Получаем число от 0 до 5: `random.nextInt(6)`.
3. Прибавляем 10 и получаем число от 10 до 15.

Общая формула для небольших учебных диапазонов, где `minValue <= maxValue`:

```java
random.nextInt(maxValue - minValue + 1) + minValue
```

Самостоятельно замените диапазон на от −3 до 3 включительно. Запустите программу два раза. Ответьте: обязаны ли за десять попыток встретиться все семь допустимых чисел?

## Задание 3. Массив своего варианта — 20 минут

Определите вариант по номеру в журнале:

`вариант = ((номер − 1) % 5) + 1`.

Например, номер 7 даёт вариант 2. Здесь `%` — остаток от деления.

| Вариант | Размер массива | Минимальное значение | Максимальное значение | Что дополнительно посчитать |
|---|---:|---:|---:|---|
| 1 | 10 | 1 | 20 | Количество чётных элементов |
| 2 | 12 | −10 | 10 | Количество положительных элементов |
| 3 | 8 | −20 | −1 | Количество элементов меньше −10 |
| 4 | 15 | 0 | 30 | Количество элементов, кратных 3, включая 0 |
| 5 | 10 | −5 | 15 | Количество элементов от 0 до 10 включительно |

В классе `ArrayWork` используйте заготовку. В ней пока стоят параметры варианта 1 — замените их своими.

```java
import java.util.Random;

public class ArrayWork {
    public static void main(String[] args) {
        Random random = new Random();
        int size = 10;
        int minValue = 1;
        int maxValue = 20;
        int[] numbers = new int[size];

        for (int index = 0; index < numbers.length; index++) {
            numbers[index] = random.nextInt(maxValue - minValue + 1) + minValue;
        }

        System.out.print("Массив: ");
        for (int index = 0; index < numbers.length; index++) {
            System.out.print(numbers[index] + " ");
        }
        System.out.println();
    }
}
```

`int[] numbers` — переменная для массива целых чисел. `new int[size]` создаёт массив указанной длины; первоначально все его элементы равны нулю. Затем первый цикл заменяет их случайными значениями.

Индексы начинаются с нуля. У массива длиной 10 допустимы индексы от 0 до 9. Поэтому условие обхода — `index < numbers.length`, а не `index <= numbers.length`.

`numbers[index]` — один элемент массива. `numbers.length` — его длина, без круглых скобок. `print` продолжает текущую строку, `println` завершает её.

Проверьте: выведено нужное количество элементов; каждый входит в диапазон вашего варианта.

## Задание 4. Характеристики массива — 25 минут

Продолжайте писать внутри `main`, после вывода массива.

### 4.1. Сумма и среднее

```java
int sum = 0;
for (int index = 0; index < numbers.length; index++) {
    sum += numbers[index];
}

double average = (double) sum / numbers.length;
System.out.println("Сумма: " + sum);
System.out.println("Среднее: " + average);
```

`sum += numbers[index]` означает `sum = sum + numbers[index]`. До обхода сумма равна нулю, после каждой итерации к ней добавляется очередной элемент.

Если оба операнда деления имеют тип `int`, Java выполняет целочисленное деление: `7 / 2` даст 3. Даже запись `double result = 7 / 2` даст 3.0: дробная часть теряется до присваивания.

`(double) sum` преобразует сумму перед делением. Поэтому `7.0 / 2` даст 3.5.

### 4.2. Минимум и максимум

Реализуйте самостоятельно по алгоритму:

1. Создайте переменные `minimum` и `maximum`. Начальное значение каждой — `numbers[0]`.
2. Обойдите остальные элементы, начиная с индекса 1.
3. Если очередной элемент меньше `minimum`, обновите минимум.
4. Если очередной элемент больше `maximum`, обновите максимум.
5. Выведите оба результата.

Почему нельзя начинать с `maximum = 0`? В варианте 3 все числа отрицательные. Ноль больше каждого из них, хотя в самом массиве нуля нет. Первый элемент подходит для начала поиска, потому что он действительно принадлежит массиву. В этой работе массивы всегда непустые.

### 4.3. Количество элементов по условию

1. Перед циклом создайте `int count = 0;`.
2. Обойдите массив.
3. Внутри цикла проверьте условие вашего варианта через `if`.
4. Если условие выполнено, увеличьте `count` на один.
5. После цикла выведите результат и подпишите, что именно считали.

Подсказки: чётность — `value % 2 == 0`; кратность трём — `value % 3 == 0`; принадлежность диапазону — `value >= left && value <= right`. Вместо `value` подставьте текущий элемент массива.
