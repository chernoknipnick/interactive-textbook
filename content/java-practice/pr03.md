# ПР03. Собственные методы

Продолжительность: 90 минут. Предыдущая работа — ПР02 «Циклы и массивы». Теоретическая основа — новая лекция «Методы (процедуры и функции) в Java».

## Цель

Научиться объявлять и вызывать собственные методы, передавать им данные и получать результат через `return`. Переработать программу из ПР02: вычисления останутся прежними, но каждое получит своё имя и отдельное место в программе.

Понадобятся: работающая среда Java, исходник `ArrayWork` из ПР02, знание циклов, массивов и условий. Все методы сегодня — `static`, внутри одного класса. Классы объектов и `this` пока не нужны.

## 1. Подготовка — 5 минут

Создайте файл `MethodsWork.java` с классом `MethodsWork`. Прежний `ArrayWork.java` сохраните: в конце сравним две версии.

```java
public class MethodsWork {
    public static void main(String[] args) {
        printTitle();
    }

    static void printTitle() {
        System.out.println("Практическая работа: собственные методы");
    }
}
```

Метод `printTitle` объявлен **внутри класса, но снаружи `main`**. Закрывающая скобка `main` стоит перед его объявлением. В Java нельзя объявить обычный метод внутри другого метода.

`printTitle();` — вызов метода. При запуске Java начинает с `main`, встречает вызов, выполняет тело `printTitle`, затем возвращается в `main` к следующей инструкции. Если метод только объявлен, но нигде не вызван, его тело не выполнится.

## 2. Метод без возвращаемого значения — 15 минут

Ниже `printTitle`, перед последней скобкой класса, добавьте:

```java
static void printSquare(int number) {
    int result = number * number;
    System.out.println("Квадрат числа " + number + " = " + result);
}
```

Внутри `main`, после `printTitle();`, добавьте:

```java
printSquare(4);
printSquare(7);
```

Разбор объявления:

| Часть | Значение |
|---|---|
| `static` | Позволяет в этой работе вызывать метод из `main` без создания объекта |
| `void` | Метод не возвращает вызывающему коду значение |
| `printSquare` | Имя метода |
| `int number` | Параметр: локальное имя входного целого числа |
| `result` | Локальная переменная, доступная только внутри этого метода |

В объявлении `number` называется **параметром**, а число `4` в вызове — **аргументом**. При первом вызове параметр получает 4, при втором — 7.

Ожидаемые результаты: 16 и 49. Самостоятельно добавьте третий вызов с числом −3.

`void` не означает «ничего не делает»: метод выполняет действие — печатает. Но присвоить его результат переменной нельзя: значения для присваивания он не возвращает.

## 3. Та же задача с возвратом результата — 15 минут

Добавьте ещё один метод рядом с предыдущими:

```java
static int square(int number) {
    return number * number;
}
```

В `main` добавьте:

```java
int savedSquare = square(4);
System.out.println("Сохранённый результат: " + savedSquare);
System.out.println("Сумма квадратов: " + (square(3) + square(4)));
```

`int` перед именем метода — тип результата. `return` завершает текущий вызов и передаёт значение туда, где метод вызвали. Поэтому `square(4)` можно использовать как число 16: сохранить, сравнить или сложить с другим значением.

Важно: `System.out.println` показывает значение человеку, а `return` отдаёт его программе. Одно действие не заменяет другое.

Самостоятельно:

1. Предскажите сумму квадратов 3 и 4, затем запустите программу.
2. Используйте `square(6)` внутри условия: если результат больше 30, выведите сообщение.
3. Объясните, почему `int answer = printSquare(6);` не скомпилируется. В сдаваемом исходнике такой строки быть не должно.

## 4. Перенос обработки массива в методы — 35 минут

Оставьте свой вариант из ПР02. Формула по номеру в журнале: `((номер - 1) % 5) + 1`.

| Вариант | Размер | Диапазон включительно | Условие для `countMatching` |
|---|---:|---|---|
| 1 | 10 | от 1 до 20 | Чётные элементы |
| 2 | 12 | от −10 до 10 | Положительные элементы |
| 3 | 8 | от −20 до −1 | Элементы меньше −10 |
| 4 | 15 | от 0 до 30 | Кратные трём, включая ноль |
| 5 | 10 | от −5 до 15 | Элементы от 0 до 10 включительно |

Таблица совпадает с ПР02: новая задача — разделить код на методы, а не заново разобраться с условием варианта.

### 4.1. Массив и вывод

Перенесите в `main` создание генератора, массива и цикл случайного заполнения из своей ПР02. В начале файла, **перед объявлением класса**, нужен `import java.util.Random;`.

Вынесите вывод массива в метод:

```java
static void printArray(int[] values) {
    for (int index = 0; index < values.length; index++) {
        System.out.print(values[index] + " ");
    }
    System.out.println();
}
```

Вызов в `main`:

```java
System.out.print("Массив: ");
printArray(numbers);
```

`numbers` — имя переменной в `main`, `values` — имя параметра метода. Имена могут различаться. В этот вызов передаётся значение ссылки на тот же массив; копия всех элементов автоматически не создаётся. Наши методы только читают элементы и не изменяют их.

### 4.2. Сумма и среднее

Добавьте методы:

```java
static int sum(int[] values) {
    int total = 0;
    for (int index = 0; index < values.length; index++) {
        total += values[index];
    }
    return total;
}

static double average(int[] values) {
    return (double) sum(values) / values.length;
}
```

Здесь один ваш метод вызывает другой: `average` получает сумму через `sum`. Приведение `(double)` выполняется **до деления**, чтобы сохранить дробную часть.

В `main` вызывайте так:

```java
System.out.println("Сумма: " + sum(numbers));
System.out.println("Среднее: " + average(numbers));
```

`total` существует внутри `sum`. Обращаться к нему из `main` нельзя. Передать результат наружу позволяет `return total;`.

### 4.3. Максимум — образец

```java
static int findMax(int[] values) {
    int maximum = values[0];
    for (int index = 1; index < values.length; index++) {
        if (values[index] > maximum) {
            maximum = values[index];
        }
    }
    return maximum;
}
```

Поставьте `return` после цикла: сначала нужно просмотреть все элементы. Если вернуть значение на первой итерации, метод завершится раньше времени.

### 4.4. Два метода самостоятельно

Напишите методы по заготовкам. Замените многоточия своим кодом: в Java они здесь не являются готовыми командами.

```text
static int findMin(int[] values) {
    ...
}

static int countMatching(int[] values) {
    ...
}
```

Для `findMin`: начальный минимум — первый элемент, обход с индекса 1, обновление при меньшем значении, возврат после цикла.

Для `countMatching`: начальный счётчик — ноль, обход всех элементов, проверка **своего** условия из таблицы, увеличение счётчика, возврат после цикла.

В `main` выведите результаты `findMax(numbers)`, `findMin(numbers)` и `countMatching(numbers)`. Укажите в подписи, какое условие считаете.

Условие использования методов этой работы: массив не равен `null` и содержит хотя бы один элемент. Обработку пустого массива и исключения сегодня не добавляем.

В итоговом `main` должны остаться вызовы методов, создание и заполнение массива. Старые циклы вычисления суммы, минимума и максимума из ПР02 удалите из новой программы: иначе задача разделения кода не выполнена.
