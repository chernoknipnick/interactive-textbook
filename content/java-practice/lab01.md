## Вариант 1 (студент)

### Задание 1. Примитивные типы

1. Объявите переменные всех типов: `byte`, `short`, `int`, `long`, `float`, `double`, `char`, `boolean`.
    
2. Присвойте им произвольные значения.
    
3. Выведите значения на экран.
    

### Задание 2. Арифметика

1. Вычислите:
    
    - остаток от деления `37` на `6`;
        
    - целую часть от деления `37` на `6`.
        
2. Используйте операции `++` и `--` для изменения переменной.
    

### Задание 3. Логика

1. Проверьте, входит ли число `x = 15` в диапазон `[10; 20]`.
    
2. Напишите выражение, которое проверяет: «x делится на 2 и на 3 одновременно».
    

### Задание 4. Побитовые операции

1. Вычислите:
    
    ```java
    int a = 45, b = 12;
    System.out.println(a & b);
    System.out.println(a | b);
    System.out.println(a ^ b);
    ```
    
2. Сдвиньте число `13` влево на 3 позиции. Объясните результат.
    

### Задание 5. Применение

Напишите программу, которая проверяет, чётное ли число, используя побитовую операцию.

## Вариант 4 (студент)

### Задание 1. Примитивные типы

1. Объявите переменные: `short`, `long`, `float`, `double`, `char`, `boolean`.
    
2. Инициализируйте их и выведите значения.
    

### Задание 2. Арифметика

1. Найдите остаток от деления `123` на `10`.
    
2. Вычислите сумму цифр числа `12345`.
    

### Задание 3. Логика

1. Проверьте выражение `(a > b) && (b > 0)` для `a = 12, b = 7`.
    
2. Составьте выражение: «год високосный, если он делится на 4, но не делится на 100, или делится на 400».
    

### Задание 4. Побитовые операции

1. Вычислите:
    
    ```java
    int a = 200, b = 150;
    System.out.println(a & b);
    System.out.println(a | b);
    System.out.println(a ^ b);
    ```
    
2. Сдвиньте число `256` вправо на 4 позиции. Объясните результат.
    

### Задание 5. Применение

Реализуйте программу: шифрование числа XOR-ключом.  
Например:

```java
int number = 123;
int key = 99;
int encrypted = number ^ key;
int decrypted = encrypted ^ key;
```
