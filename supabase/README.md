# Кабинет и группы

Статические страницы находятся в dist/account. Вход и восстановление пароля обслуживает Supabase Auth. Профили и группы хранятся в PostgreSQL с RLS.

## Настройка проекта

1. Выполнить 001_accounts_and_groups.sql, затем 002_feedback.sql в отдельном проекте Supabase.
2. В Authentication → URL Configuration задать Site URL и разрешённый Redirect URL как https://chernoknipnick.github.io/interactive-textbook/account/.
3. В dist/account/config.js указать URL проекта и существующий publishable key.
4. Зарегистрировать собственный аккаунт через страницу кабинета и подтвердить почту.
5. В SQL Editor назначить роль преподавателя точному аккаунту, подставив его UUID из Authentication → Users.

```sql
insert into public.textbook_teachers(user_id)
values ('UUID-ВАШЕГО-АККАУНТА')
on conflict do nothing;
```

Преподаватель создаёт группы и передаёт участникам код приглашения. Студент может вступить в несколько групп. При смене кода действующие участники сохраняются. Повторный ввод текущего кода не создаёт дублей.

Студент читает свой профиль и свои группы. Преподаватель читает участников групп, которыми владеет. Права преподавателя хранятся в отдельной таблице с закрытой записью через клиент. Код приглашения доступен владельцу группы через RPC.

Для массовой регистрации с подтверждением почты настройте SMTP в Supabase. У встроенной тестовой отправки есть ограничения. Форма восстановления использует тот же почтовый сервис.

## Обновления и предложения

Список изменений сайта хранится в dist/site-updates.json. Новые версии добавляются в начало массива с уникальным id. Кнопка «Что нового» показывает непрочитанное обновление, отметки сохраняются в браузере посетителя.

Форма принимает текст, ссылку на страницу учебника и необязательное имя или группу. Посетители могут отправлять сообщения через ограниченную RPC-функцию. Читать обращения и изменять их состояние могут назначенные преподаватели в личном кабинете.

## Проверка прав

Тест создаёт временный кластер PostgreSQL на случайном локальном порту и останавливает его после проверки. Нужны PostgreSQL и psycopg2.

```sh
python supabase/test_access.py --pg-bin "C:/Program Files/PostgreSQL/18/bin"
```

Проверяются изоляция профилей и групп, запрет повышения роли через клиент, повторная миграция, одновременное вступление, смена кода и исключение участника.
